# campus-wall-frontend 开发文档

## 项目简介

campus-wall-frontend 是校园墙项目的用户端前端应用，面向在校大学生，提供帖子浏览、发布、AI 学长问答、私信聊天等功能。基于 uni-app 跨端框架开发，一套代码可同时编译为 H5 网页和微信小程序。

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| TypeScript | 4.9.4 | 开发语言 |
| Vue | 3.4.21 | 前端框架 |
| uni-app | 3.0.0 | 跨端开发框架 |
| Vite | 5.2.8 | 构建工具 |
| SCSS/Sass | 1.99.0 | 样式预处理器 |
| vue-i18n | 9.1.9 | 国际化 |

## 开发环境搭建

### 1. 环境要求

- Node.js 18+
- npm 或 pnpm
- HBuilderX 或 VS Code（推荐 VS Code + uni-app 插件）
- 微信开发者工具（如需调试小程序）

### 2. 安装依赖

```bash
cd campus-wall-frontend
npm install
```

### 3. 配置后端地址

编辑 `src/utils/request.js`：

```javascript
const BASE_URL = 'http://localhost:8080'  // 开发环境
```

或编辑 `.env.development`：

```
VUE_APP_BASE_URL=http://localhost:8080
```

### 4. 启动开发服务器

```bash
# H5 开发模式
npm run dev:h5

# 微信小程序开发模式
npm run dev:mp-weixin

# 其他平台
npm run dev:mp-alipay
npm run dev:mp-baidu
```

### 5. 访问

- H5：浏览器打开终端显示的地址（如 `http://localhost:5173`）
- 微信小程序：微信开发者工具打开 `dist/dev/mp-weixin`

## 核心模块说明

### 1. 路由与页面配置 (pages.json)

uni-app 使用 `pages.json` 配置页面路由和 tabBar：

```json
{
  "pages": [
    { "path": "pages/index/index", "style": { "navigationBarTitleText": "圈子" } },
    { "path": "pages/discover/index", "style": { "navigationBarTitleText": "发现" } },
    ...
  ],
  "tabBar": {
    "list": [
      { "pagePath": "pages/index/index", "text": "圈子" },
      { "pagePath": "pages/discover/index", "text": "发现" },
      { "pagePath": "pages/ai/chat/index", "text": "AI" },
      { "pagePath": "pages/message/index/index", "text": "私信" },
      { "pagePath": "pages/user/index/index", "text": "我的" }
    ]
  }
}
```

**5个 Tab 页面**：
1. **圈子** - 帖子列表首页
2. **发现** - 分类浏览、搜索
3. **AI** - AI 学长聊天
4. **私信** - 消息列表、实时聊天
5. **我的** - 个人中心

### 2. HTTP 请求封装 (utils/request.js)

基于 `uni.request` 封装的 HTTP 客户端：

```javascript
// 请求拦截：自动添加 Token
// 响应拦截：统一错误处理

request.get('/api/v1/posts/list', { page: 1, size: 10 })
request.post('/api/v1/posts/publish', { title, content })
```

特性：
- 自动携带 JWT Token
- 统一的错误提示
- 请求/响应日志

### 3. 认证模块 (utils/auth.js)

```javascript
// Token 管理
getToken()          // 从 storage 获取 Token
setToken(token)     // 保存 Token
clearToken()        // 清除 Token

// 登录状态
isLoggedIn()        // 是否已登录
```

### 4. 帖子卡片组件 (components/post-card/)

核心组件，在首页列表中展示帖子：

```vue
<post-card
  :post="post"
  @like="handleLike"
  @comment="handleComment"
  @share="handleShare"
/>
```

Props：
- `post` - 帖子数据对象

Events：
- `like` - 点赞/取消点赞
- `comment` - 点击评论
- `share` - 点击分享

### 5. AI 聊天页面 (pages/ai/chat/)

AI 学长对话界面：
- 消息列表（用户消息 + AI 回复）
- 输入框发送消息
- 加载状态显示
- 支持 Markdown 渲染

### 6. WebSocket 私信 (utils/websocket.js)

```javascript
// 建立连接
ws.connect(url, token)

// 发送消息
ws.send({ type: 'TEXT', toUserId, content })

// 监听消息
ws.onMessage((msg) => {
  // 处理接收到的消息
})

// 断开连接
ws.close()
```

### 7. 组合式函数 (composables/)

Vue 3 Composition API 封装的业务逻辑：

```javascript
// usePostFeed.js - 帖子列表逻辑
const { posts, loading, hasMore, loadMore, refresh } = usePostFeed(categoryId)

// usePostDetail.js - 帖子详情逻辑
const { post, comments, loadDetail, submitComment } = usePostDetail(postId)

// useOptimisticLike.js - 乐观更新点赞
const { liked, likeCount, toggleLike } = useOptimisticLike(postId, initialLiked)

// useComments.js - 评论逻辑
const { comments, loading, loadComments, addComment } = useComments(postId)
```

## 组件开发规范

### 创建新组件

1. 在 `src/components/` 下创建目录（如 `my-component/`）
2. 创建 `index.vue` 文件
3. 使用 easycom 自动导入（无需手动注册）

```vue
<!-- src/components/my-component/index.vue -->
<script setup lang="ts">
interface Props {
  title: string
  description?: string
}

const props = withDefaults(defineProps<Props>(), {
  description: ''
})

const emit = defineEmits<{
  (e: 'click'): void
}>()
</script>

<template>
  <view class="my-component" @click="emit('click')">
    <text class="title">{{ title }}</text>
    <text v-if="description" class="desc">{{ description }}</text>
  </view>
</template>

<style scoped lang="scss">
.my-component {
  padding: 16px;
  background: #fff;
  border-radius: 8px;

  .title {
    font-size: 16px;
    font-weight: 600;
  }

  .desc {
    font-size: 14px;
    color: #666;
    margin-top: 8px;
  }
}
</style>
```

### 创建新页面

1. 在 `src/pages/` 下创建目录（如 `activity/`）
2. 创建 `index.vue` 文件
3. 在 `pages.json` 中注册

```json
{
  "pages": [
    {
      "path": "pages/activity/index",
      "style": {
        "navigationBarTitleText": "活动"
      }
    }
  ]
}
```

## 跨端适配

### 条件编译

```vue
<template>
  <!-- #ifdef H5 -->
  <div>H5 专用代码</div>
  <!-- #endif -->

  <!-- #ifdef MP-WEIXIN -->
  <view>微信小程序专用代码</view>
  <!-- #endif -->
</template>
```

### 平台判断

```javascript
// #ifdef H5
console.log('当前是 H5 平台')
// #endif

// #ifdef MP-WEIXIN
console.log('当前是微信小程序')
// #endif
```

## 构建与部署

```bash

# 输出到 dist/build/h5/

npm run build:mp-weixin
# 输出到 dist/build/mp-weixin/
```

### H5 部署

将 `dist/build/h5/` 目录下的文件部署到静态服务器或 CDN。

1. 执行 `npm run build:mp-weixin`
2. 微信开发者工具打开 `dist/build/mp-weixin`
3. 点击「上传」按钮
4. 在小程序后台提交审核

## 常见问题

### Q: npm install 失败？

```bash
# 清除缓存后重试
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Q: H5 页面空白？

1. 检查 `vite.config.ts` 配置
2. 检查浏览器控制台报错
3. 确认后端服务已启动且 CORS 配置正确

### Q: 微信小程序编译报错？

1. 确认 `project.config.json` 中的 `appid` 已配置
2. 检查是否使用了小程序不支持的 API
3. 使用条件编译区分平台代码

### Q: 图片上传失败？

1. 检查 MinIO 服务是否正常运行
2. 检查后端 `/api/v1/files/upload` 接口
3. 检查图片大小是否超过限制（默认 10MB）

### Q: uni-app 组件样式不生效？

uni-app 组件需要使用 `scoped` 样式或深度选择器：

```vue
<style scoped>
/* 深度选择器 */
::v-deep .uni-input {
  color: red;
}
</style>
```
