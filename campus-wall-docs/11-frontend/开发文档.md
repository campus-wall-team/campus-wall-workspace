# campus-wall-frontend 开发文档

## 项目简介

campus-wall-frontend 是校园墙项目的用户端前端应用，面向在校大学生，提供帖子浏览、发布、AI 学长问答、私信聊天等功能。基于 uni-app 跨端框架开发，一套代码可同时编译为 H5 网页和微信小程序。

## 开发环境搭建

### 1. 环境要求

- Node.js 18+
- npm 或 pnpm
- HBuilderX 或 VS Code（推荐 VS Code + uni-app 插件）
- 微信开发者工具（如需调试小程序）

### 2. 安装依赖

```bash
cd campus-wall-frontend
npm install
```

### 3. 配置后端地址

后端地址通过 Vite 环境变量注入，**不要硬编码改 request.js**。请求基址来自 `src/config/index.ts` 的 `config.apiBaseUrl`，其读取 `import.meta.env.VITE_API_BASE_URL`（WebSocket 同理读 `VITE_WS_BASE_URL`）：

```typescript
// src/config/index.ts
export const config = {
  apiBaseUrl: import.meta.env.VITE_API_BASE_URL || 'http://localhost:8080',
  wsBaseUrl:  import.meta.env.VITE_WS_BASE_URL  || 'ws://localhost:8080',
  // ...
} as const
```

`src/utils/request.js` 直接 `import { config } from '@/config'` 并取 `config.apiBaseUrl` 作为 BASE_URL。

规范做法：仓库只提供 `.env.example` 模板（不存在 `.env.development`），复制为 `.env.local` 后填入实际地址（`*.local` 已被 `.gitignore` 忽略，不会提交）：

```bash
cp .env.example .env.local
```

```
# .env.local
VITE_API_BASE_URL=http://172.21.160.221:8080
VITE_WS_BASE_URL=ws://172.21.160.221:8080
```

> 注意：变量名是 `VITE_API_BASE_URL`（旧文档的 `VUE_APP_BASE_URL` 已作废）。前后端同机用 H5 浏览器预览时可用 `http://localhost:8080`；但微信开发者工具/真机必须填后端那台机器的局域网 IP（真机访问 localhost 会失败，用 `ip addr` / `hostname -I` 查 IP）。`.env.local` 在 dev:h5 / dev:mp-weixin / build 各模式均会加载。

### 4. 启动开发服务器

```bash
# H5 开发模式
npm run dev:h5

# 微信小程序开发模式
npm run dev:mp-weixin

# 其他平台
npm run dev:mp-alipay
npm run dev:mp-baidu
```

### 5. 访问

- H5：浏览器打开终端显示的地址（如 `http://localhost:5173`）
- 微信小程序：微信开发者工具打开 `dist/dev/mp-weixin`

## 核心模块说明

### 1. 路由与页面配置 (pages.json)

uni-app 使用 `pages.json` 配置页面路由和 tabBar。页面为扁平 `.vue` 文件（如 `pages/discover/discover.vue`、`pages/ai/chat.vue`），并非「带 index 的子目录」结构；当前共 **32 个页面**。tabBar 启用了自定义渲染（`custom: true`，由 `components/CustomTabBar` 实现）：

```json
{
  "pages": [
    { "path": "pages/index/index", "style": { "navigationBarTitleText": "圈子" } },
    { "path": "pages/discover/discover", "style": { "navigationBarTitleText": "发现" } }
  ],
  "tabBar": {
    "custom": true,
    "list": [
      { "pagePath": "pages/index/index", "text": "圈子" },
      { "pagePath": "pages/discover/discover", "text": "发现" },
      { "pagePath": "pages/ai/chat", "text": "AI" },
      { "pagePath": "pages/message/message", "text": "私信" },
      { "pagePath": "pages/user/profile", "text": "我的" }
    ]
  }
}
```

**5个 Tab 页面**（真实路径）：
1. **圈子** - `pages/index/index` 帖子列表首页
2. **发现** - `pages/discover/discover` 分类浏览、附近大学区域筛选
3. **AI** - `pages/ai/chat` AI 学长聊天
4. **私信** - `pages/message/message` 消息列表、实时聊天
5. **我的** - `pages/user/profile` 个人中心

### 2. HTTP 请求封装 (utils/request.js)

基于 `uni.request` 封装的 HTTP 客户端。基址来自 `src/config/index.ts` 的 `config.apiBaseUrl`（即 `VITE_API_BASE_URL`），不在 request.js 内硬编码：

```javascript
import { config } from '@/config'
const BASE_URL = config.apiBaseUrl

request.get('/api/v1/posts/list', { page: 1, size: 10 })
request.post('/api/v1/posts/publish', { content })
```

特性：
- 自动携带 JWT Token
- 统一的错误提示
- 请求/响应日志

### 3. 认证模块 (utils/auth.js)

```javascript
// Token 管理
getToken()          // 从 storage 获取 Token
setToken(token)     // 保存 Token
clearToken()        // 清除 Token

// 登录状态
isLoggedIn()        // 是否已登录
```

### 4. 公共组件 (components/)

当前仅 3 个公共组件，通过 easycom 自动导入：

- **AvatarStack** - 组队场景的成员头像叠放展示。
- **CustomTabBar** - 自定义底部 5 Tab 栏。`pages.json` 中 `tabBar.custom=true`，原生 tabBar 被隐藏，由该组件统一渲染图标/选中态/跳转，便于做高亮与徽标等定制。
- **my-navbar** - 自定义顶部导航栏（适配状态栏/安全区）。

> 帖子卡片、列表项等不再抽成独立组件，而是直接在各页面（如 `pages/index/index.vue`、`pages/post/detail.vue`）内用 Tailwind 原子类布局实现。

### 5. AI 聊天页面 (pages/ai/chat.vue)

AI 学长对话界面：
- 消息列表（用户消息 + AI 回复）
- 输入框发送消息，统一走单一入口 `aiApi.agent`（`POST /api/v1/ai-senior/agent`），后端大模型自主判断调用工具
- 加载状态显示
- **Markdown 渲染**：用 `marked` 把 AI 回复解析为 HTML，再交给 `<rich-text :nodes="...">` 显示（`marked.parse(content, { breaks: true, gfm: true })`）
- **＋ 选图上传**：`uni.chooseImage` 选图后 `uni.uploadFile` 上传，得到 object name 随消息一起发出（`aiApi.agent` 的 `images` 参数）。一份图既能做「配图提问找帖」（后端 VLM 看图说话后并入帖子检索），也能「让学长照图发帖」（被判为发帖意图时图随草稿）。
- **对话内联 AI 发帖**：被判为发帖意图时，直接在对话里出**草稿卡片**（不跳页），支持改稿 / 确认发布 / 取消；草稿编辑期间顶部有「✍️ 发帖中」常驻状态条，即便草稿卡片被滚走也能退出。

```typescript

```

### 8. AI 接口（问答收口为单一入口 + AI 发帖三方法）

AI 问答接口已统一收口，不再存在 `/chat`、`/chat/stream`，也不存在客户端侧直连 `/match-posts` 的「问答 / 匹配」双路。`aiApi`（`src/api/index.js`）共 6 个方法：问答 3 个（agent / getHistory / getHistoryDetail）+ AI 发帖 3 个（startDraft / resumeDraft / cancelDraft）：

```javascript
// 智能助手单一入口：后端大模型自主判断调用工具（查知识库 / 查帖子 / 两者综合）
// images = 对话内上传图片的 object name；后端 VLM 看图后并入检索
aiApi.agent(question, conversationId, images)            // POST   /api/v1/ai-senior/agent
aiApi.getHistory(userId)                                 // GET    /api/v1/ai-senior/history/list
aiApi.getHistoryDetail(sessionId)                        // GET    /api/v1/ai-senior/history/detail

// AI 发帖（对话内联）：出草稿 → 续接(改稿/发布/取消) → 丢弃草稿
aiApi.startDraft(conversationId, text, images)           // POST   /api/v1/ai-senior/posts/draft
aiApi.resumeDraft(draftId, action, patch)                // POST   /api/v1/ai-senior/posts/resume/{draftId}  action: 'edit' | 'publish' | 'cancel'
aiApi.cancelDraft(draftId)                               // DELETE /api/v1/ai-senior/posts/draft/{draftId}
```

`/api/v1/ai-senior/agent` 由后端轻量 Planner-Executor agent 处理：自动规划、调用只读工具、反幻觉判定后再接地合成答案，返回 `{ answer, posts(匹配到的帖子卡片), conversationId }`，前端按需把 `posts` 渲染成帖子卡片。AI 发帖三方法 `startDraft/resumeDraft/cancelDraft` 由后端转发到 AI 发帖子图（出草稿 → 改稿/发布/取消），前端在对话内联渲染草稿卡片。AI 偏好设置走独立的 `src/api/aiPreference.js`（`/api/v1/ai-preference/get|save|system-prompt`）。

## 核心业务功能

近期迭代落地了以下面向业务的能力，文档同步补充：

- **板块化发布**：发布页 `pages/publish/publish.vue` 按 `boardCode` 切换动态字段区与校验。板块包含二手交易（`secondhand`，价格/可面议，面议时价格留空）、兼职发布（`parttime`，薪资必填 + 信息费）、推广（`promotion`，Banner 大图）、组队（`team`）以及推荐（`recommend`）；不同板块提交的字段（price/negotiable/salary/infoFee/bannerImage 等）和必填校验各不相同。
- **集市帖子联系卖家**：帖子详情页 `pages/post/detail.vue` 对带联系方式的二手/推广帖提供「一键复制联系方式」（`copyContact` → `uni.setClipboardData`）。
- **组队 join / leave**：`postApi.joinTeam(postId)` / `postApi.leaveTeam(postId)` 对应 `POST /api/v1/posts/{id}/join`、`POST /api/v1/posts/{id}/leave`，组队成员头像用 `AvatarStack` 叠放展示。
- **排行榜**：`pages/leaderboard`、`pages/hot-posts` 配合 `rankApi`（`GET /api/v1/ranks/posts` 热帖榜、`GET /api/v1/ranks/search-hot` 热搜榜，支持 period、scope 参数）；旧的 `postApi.getLeaderboard`（`GET /api/v1/posts/leaderboard`，按浏览量）仍保留。
- **AI 偏好**：`pages/ai/preference.vue` 配合 `aiPreference.js`（`/api/v1/ai-preference/*`）让用户配置 AI 学长的回答风格 / system prompt。
- **发现页附近大学区域筛选**：`pages/discover/discover.vue` 通过附近学校/校区接口与 `scope` 等参数，按地理区域过滤帖子。
- **对话内联 AI 发帖**：`pages/ai/chat.vue` 内联出草稿、确认/改稿/发布，另有独立草稿页 `pages/ai/post-draft.vue`；均走 `aiApi.startDraft` / `resumeDraft` / `cancelDraft`（`/api/v1/ai-senior/posts/draft|resume/{id}`）。
- **对话内配图找帖**：聊天里上传图片，`aiApi.agent` 的 `images` 参数（object name）交后端 VLM 看图说话后并入帖子检索匹配。

## 常见问题

### Q: npm install 失败？

```bash
# 清除缓存后重试
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Q: H5 页面空白？

1. 检查 `vite.config.ts` 配置
2. 检查浏览器控制台报错
3. 确认后端服务已启动且 CORS 配置正确

### Q: 微信小程序编译报错？

1. 确认 `project.config.json` 中的 `appid` 已配置
2. 检查是否使用了小程序不支持的 API
3. 使用条件编译区分平台代码

### Q: 图片上传失败？

1. 检查 MinIO 服务是否正常运行
2. 检查后端 `/api/v1/files/upload` 接口
3. 检查图片大小是否超过限制（默认 10MB）

### Q: uni-app 组件样式不生效？

uni-app 组件需要使用 `scoped` 样式或深度选择器：

```vue
<style scoped>
/* 深度选择器 */
::v-deep .uni-input {
  color: red;
}
</style>
```
