# 04 · 推广板块

> 依赖 [`01-板块分类体系-基础架构.md`](./01-板块分类体系-基础架构.md)。本篇重点是**前端视觉差异化**:专属高亮标签 + Banner 撑满大图,让广告帖与普通帖一眼区分。`banner_object_name`/`contact` 字段已在 `01/V3.3` 建好。

## 一、概述

### 目标
推广板块(`code=promotion`)用于商家广告帖。核心诉求:**视觉上与普通吐槽/求助帖拉开显著差距,让用户一眼识别这是推广,避免欺骗感。**

1. **专属高亮标签**:帖子右上角或标题前强制打 `[推广]` / `[赞助]` Tag,带微渐变背景,配色用**极客蓝**或**品牌金**。
2. **富媒体大图**:普通帖是三宫格小图,推广帖享有"撑满卡片宽度的横向大图(Banner)"特权。
3. **联系方式**:展示在主页卡片与详情页,可一键复制(同 `02`)。

### 对应需求原文
> 广告帖的视觉呈现必须和普通同学的吐槽、求助帖拉开显著的差距,要让用户一眼就知道这是商家的推广,避免产生欺骗感。
> 专属高亮标签:在帖子右上角或标题前,强制打上一个带有微渐变背景的 [推广] 或 [赞助] 专属 Tag,颜色建议用极客蓝或品牌金。
> 富媒体大图展示:广告帖往往是一张精心设计的海报。在列表中,普通帖子可能是三宫格小图,但广告帖可以赋予特权,直接展示为一张撑满卡片宽度的横向大图 (Banner)。

## 二、现状与可复用资产

| 资产 | 位置 | 复用点 |
|------|------|--------|
| `banner_object_name` 字段 | `post` 表(`01/V3.3`) | 存 Banner 大图 |
| 单图上传 | `publish.vue` 现有 `uploadSingleImage` / 图片选择 | Banner 上传 |
| objectName→URL | `MinioUtil.getFileUrl` + `PostConverter`(`01` 已补 `bannerImage`) | 渲染 Banner |
| 三宫格渲染 | `index.vue` 普通帖图片区(`grid-cols-3`) | 推广帖用 `v-if` 分支覆盖 |
| 现有渐变类 | `.hot-banner-gradient`、`gradient-primary`(前端已定义) | 参考,或新增推广专属渐变 |
| 复制 | `copyContact`(见 `02`) | 联系方式复制 |

## 三、技术方案(如何实现)

### 3.1 [推广] 高亮标签(微渐变,极客蓝 / 品牌金)

在 `index.vue` 帖子卡片与 `detail.vue` 顶部,`post.boardCode === 'promotion'` 时渲染:

```vue
<view v-if="post.boardCode === 'promotion'" class="promo-tag">推广</view>
```

```css
/* 极客蓝(默认) */
.promo-tag {
  position: absolute;
  top: 16rpx;
  right: 16rpx;
  padding: 4rpx 16rpx;
  border-radius: 999rpx;
  font-size: 22rpx;
  color: #fff;
  background: linear-gradient(135deg, #1677ff, #69b1ff); /* 极客蓝微渐变 */
  box-shadow: 0 2rpx 8rpx rgba(22, 119, 255, 0.25);
  z-index: 2;
}
/* 品牌金(可切换) */
.promo-tag--gold {
  color: #6b4e00;
  background: linear-gradient(135deg, #ffd66b, #ffc46b);
  box-shadow: 0 2rpx 8rpx rgba(255, 196, 107, 0.3);
}
```

> 卡片容器需 `position: relative` 以承载右上角绝对定位的 Tag。文案 `推广`/`赞助` 可做成可配置常量。

### 3.2 Banner 撑满大图(覆盖三宫格)

推广帖**优先**用 Banner 大图替代默认三宫格:

```vue
<!-- 图片区:推广帖走 Banner 分支 -->
<image
  v-if="post.boardCode === 'promotion' && post.bannerImage"
  :src="post.bannerImage"
  class="promo-banner"
  mode="aspectFill"
  @tap.stop="goDetail(post.id)"
/>
<view v-else class="grid grid-cols-3 gap-2"><!-- 普通三宫格 --></view>
```

```css
.promo-banner {
  width: 100%;
  aspect-ratio: 16 / 9;      /* 横向 Banner */
  border-radius: 16rpx;
  display: block;
}
```

### 3.3 整卡视觉差异化(避免欺骗感)

推广卡片加高亮边框/底色,与普通帖进一步区分:

```css
.promo-card {
  border: 2rpx solid rgba(22, 119, 255, 0.3);
  background: linear-gradient(180deg, rgba(22,119,255,0.04), transparent 40%);
}
```

在卡片根节点按 `post.boardCode === 'promotion'` 绑定 `:class="{ 'promo-card': post.boardCode==='promotion' }"`。

### 3.4 发布页:Banner 单图上传 + 联系方式

`publish.vue` `boardCode === 'promotion'` 时,提供"上传 Banner 海报(横图)"入口(复用现有单图上传,返回 objectName 存入 `form.bannerImage`)+ 联系方式输入。提交时把 `bannerImage`(objectName)随 `PostDTO` 上送,后端存 `post.banner_object_name`。

### 3.5 联系方式展示 + 复制

同 `02`,推广卡片与详情展示 `post.contact` 并复用 `copyContact` 一键复制。

## 四、数据模型 / 接口

- 字段:`post.banner_object_name`(`varchar(500)`)、`post.contact`——`01/V3.3` 已建。
- `PostDTO` 增 `bannerImage`(objectName);`PostVO.bannerImage` 经 `PostConverter` + `minioUtil.getFileUrl` 转 URL(`01` 已说明)。
- 接口:`POST /api/v1/posts/publish` 请求体含 `bannerImage`/`contact`;列表/详情响应含 `bannerImage`(URL)/`contact`/`boardCode`。

## 六、实现步骤

1. 确认 `01/V3.3` 的 `banner_object_name` 字段、`PostConverter` 已输出 `bannerImage` URL。
2. 后端:发布落 Banner/联系方式字段。
3. 前端发布页:Banner 上传 + 联系方式。
4. 前端展示:Tag + Banner + 高亮卡 + 复制(卡片与详情)。
5. 联调:推广帖与普通帖在列表中视觉明显不同;Banner 撑满、Tag 醒目。

## 七、验收标准

- [ ] 推广帖在列表中带 `[推广]`/`[赞助]` 微渐变标签(极客蓝或品牌金),位置在右上角或标题前。
- [ ] 推广帖图片为撑满卡片宽度的横向 Banner,而非三宫格。
- [ ] 推广帖整卡视觉(边框/底色)与普通帖明显区分,用户一眼可辨。
- [ ] 联系方式展示且可一键复制(卡片与详情)。

## 八、风险与待确认项

1. **推广帖审核**:广告涉及商业内容,建议推广帖发布后 `status=0`(审核中),经管理后台 `campus-wall-monitor-ui` 审核通过再上墙(复用现有 `moderation` 流程)。待产品确认是否先审后发。
2. **配色与文案**:`[推广]` vs `[赞助]`、极客蓝 vs 品牌金,做成可配置常量,最终由设计/品牌确定。
3. **Banner 缺省**:推广帖未上传 Banner 时的回退(用三宫格 / 提示必须上传 Banner)需确认;建议推广帖**强制**要求 Banner 横图。
4. **是否计费/置顶**:推广是否与 `is_top` 置顶、曝光计费挂钩,属商业化范畴,见 [`50-business-plan`](../50-business-plan/),本期不含。
