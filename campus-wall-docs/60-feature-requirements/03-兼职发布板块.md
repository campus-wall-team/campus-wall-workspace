# 03 · 兼职发布板块

> 依赖 [`01-板块分类体系-基础架构.md`](./01-板块分类体系-基础架构.md),结构与 [`02-二手交易板块.md`](./02-二手交易板块.md) 高度一致。差异:字段为**薪资 / 信息费**(而非价格)。`salary`/`info_fee`/`contact` 字段已在 `01` 的 `V3.3` 建好。

## 一、概述

### 目标
兼职发布板块(`code=parttime`)用于发布兼职信息。与二手类似,但发布时填写的是**薪资**和**信息费**:

1. **发布时**选择"兼职发布类"后,输入薪资、信息费之类信息;联系方式可选。
2. **浏览时**薪资/信息费展示在卡片与详情;联系方式可一键复制(同 `02`)。

### 对应需求原文
> 兼职发布类与二手交易类类似,但是当用户选择该类后需要输入如薪资,信息费之类的信息,联系方式(可选)等信息,其中联系方式要直接展示在主页的帖子信息和帖子详情页等页当中,用户可以直接复制帖子当中联系方式信息。

## 二、现状与可复用资产

同 `02`,复用项一致:`BoardType.PARTTIME`(`requireSalary=true`)、`post.salary`/`info_fee`/`contact` 字段、`copyContact` 复制方法、`BusinessException` 提示链路。

> `salary`/`info_fee` 为 `varchar`(非 `decimal`),以容纳"面议""150元/天""200/单"等真实文本(见 `01/V3.3` 设计说明)。

## 三、技术方案(如何实现)

### 3.1 发布页:薪资 + 信息费 + 联系方式

`publish.vue` 板块字段区(`boardCode === 'parttime'`):

```vue
<view v-if="selectedBoardCode === 'parttime'" class="board-fields">
  <view class="field-row">
    <text class="field-label">薪资 <text class="required">*</text></text>
    <input v-model="form.salary" placeholder="如:150元/天、80/小时、面议" />
  </view>
  <view class="field-row">
    <text class="field-label">信息费</text>
    <input v-model="form.infoFee" placeholder="如:无、50元(选填)" />
  </view>
  <view class="field-row">
    <text class="field-label">联系方式</text>
    <input v-model="form.contact" placeholder="微信/手机号(选填,将展示在帖子上)" />
  </view>
</view>
```

前端校验(`submitPost`):

```js
if (selectedBoardCode.value === 'parttime' && !form.salary?.trim()) {
  uni.showToast({ title: '兼职帖请填写薪资', icon: 'none' })
  return
}
// postData 增加:salary、infoFee、contact
```

### 3.2 后端:服务端校验

`PostPublishService.publishPost` 内,沿用 `01` 的 `BoardType` 分支:

```java
BoardType board = BoardType.fromCategory(dto.getCategory());
if (board.isRequireSalary() && !StringUtils.hasText(dto.getSalary())) {
    throw new BusinessException("兼职帖必须填写薪资");
}
// 落库:post.setSalary(dto.getSalary());
//       post.setInfoFee(dto.getInfoFee());
//       post.setContact(dto.getContact());
```

### 3.3 展示 + 一键复制

卡片(`index.vue`,`post.boardCode === 'parttime'`)与详情页展示薪资/信息费 + 联系方式行,复制复用 `02` 的 `copyContact`:

```vue
<view v-if="post.boardCode === 'parttime'" class="pt-info">
  <text class="pt-salary">薪资:{{ post.salary }}</text>
  <text v-if="post.infoFee" class="pt-fee">信息费:{{ post.infoFee }}</text>
  <view v-if="post.contact" class="pt-contact" @tap.stop="copyContact(post.contact)">
    <text>联系:{{ post.contact }}</text>
    <text class="copy-btn">复制</text>
  </view>
</view>
```

## 四、数据模型 / 接口

- 字段:`post.salary`/`info_fee`(`varchar(50)`)、`post.contact`(`varchar(100)`)——`01/V3.3` 已建。
- `PostDTO`/`PostVO` 增 `salary`/`infoFee`/`contact`(VO 已含,见 01)。
- 接口:`POST /api/v1/posts/publish` 请求体含 `salary`/`infoFee`/`contact`;列表/详情响应含同名字段 + `boardCode`。

## 六、实现步骤

1. 确认 `01/V3.3` 字段、`PostDTO/PostVO` 已含字段。
2. 后端:`PostPublishService` 加兼职校验与落库。
3. 前端发布页:兼职字段区 + 校验 + 提交。
4. 前端展示:卡片与详情的薪资/信息费/联系方式/复制。
5. 联调:无薪资被拒、有薪资成功;展示与复制正常。

## 七、验收标准

- [ ] 发布页选"兼职发布",出现薪资(必填)、信息费(选填)、联系方式(选填)输入框。
- [ ] 不填薪资点发布 → 前端拦截;绕过前端 → 后端返回错误。
- [ ] 主页该帖卡片显示薪资/信息费;填了联系方式则显示并可复制。
- [ ] 详情页同样显示并可复制联系方式。

## 八、风险与待确认项

1. **字段语义**:"信息费"是否强制?当前设计为选填,如需必填可在 `BoardType` 加 `requireInfoFee` 元数据。
2. **薪资结构化**:当前 `salary` 为自由文本,不便做"薪资区间筛选"。若后续需要按薪资排序/筛选,可拆为 `salary_min`/`salary_max`/`salary_unit`,待产品确认。
3. **联系方式隐私 / 脱敏**:同 `02`,公开展示需提示;AI 入库不落明文(见 [`07`](./07-AI知识入库-Neo4j图谱.md))。
