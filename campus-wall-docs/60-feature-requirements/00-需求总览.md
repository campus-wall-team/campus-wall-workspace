# 60 · 新功能需求总览 — 板块分类 + AI 多模态助手

> 本目录是一份新需求(原文 `需求文档.txt`)拆分而成的**专题需求文档集**,每篇写清"如何实现",技术方案严格贴合 campus-wall 现有技术栈。本篇为入口:索引 + 原始需求归档 + 整体架构 + 公共数据模型 + 实施顺序 + 风险汇总。

## 一、需求来源与拆分

原始需求包含**两大块**:

1. **帖子板块分类系统** —— 主页一级 topic 增加 5 个板块(推荐 / 二手交易 / 兼职发布 / 推广 / 组队),建立"板块(父类)→ 标签(子类)"两级体系;板块只能在发布页选择;各板块差异化字段与视觉。
2. **AI 多模态助手** —— 轻量化视觉大模型对帖子图片做特征标注,结合文字存入 Neo4j;用户自然语言提问时,AI 检索匹配并推送对应帖子。**AI 是本项目主要亮点,目标:让用户少刷帖、直接问出想要的帖子。**

> ⚠️ 原文标题写"四大分类",实际列举 **5 个**板块,本系列按 5 个实现。

## 三、原始需求归档

<details>
<summary>需求文档.txt 核心内容(点击展开)</summary>

**板块分类**
- 主页 index.vue 一级 topic 增加 5 分类:推荐 / 二手交易 / 兼职发布 / 推广 / 组队。
- 五大类的子类有标签(如 `#测试`);帖子以标签形式携带,打标签后可在对应父类的子类中看到。
- 父类只能在发布页选择;选二手交易须输入价格才能发布,标签任意。
- 推荐类:存放所有帖子,除置顶外按时间线从新到旧。
- 二手交易类:发布页选该类后提醒输入价格、联系方式(可选);联系方式展示在主页与详情页,可复制。
- 兼职发布类:与二手类似,输入薪资、信息费、联系方式(可选);联系方式可复制。
- 推广类:视觉与普通帖显著拉开差距,避免欺骗感;`[推广]`/`[赞助]` 微渐变标签(极客蓝/品牌金);撑满卡片的横向 Banner 大图;联系方式可复制。
- 组队类:头像叠放效果,不展示干瘪数字(如 3/5 人);联系方式。

**AI 多模态**
- 用轻量化视觉大模型把图片标注转化后存入 Neo4j。
- 场景 1/3(有图有文):图文参照,识别图片中物品的额外特征,与用户描述一起存入;他人提问时把帖子推给他、询问确认。
- 场景 2/4(有图无文):视觉大模型对图片描述(书包特征 / 书名版本)后存入;他人提问时推送。
- 兼职、组队同理。AI 作为主要亮点,减少手动刷帖。
</details>

## 四、整体架构

```
┌───────────────────────── 小程序前端 (uni-app + Vue3) ─────────────────────────┐
│  index.vue 板块/标签 tab │ publish.vue 选板块+字段 │ 帖子卡片差异化 │ ai/chat.vue 帖子卡片 │
└───────┬───────────────────────────────────────────────────────┬───────────────┘
        │ /api/v1/posts/*                                        │ /api/v1/ai-senior/match-posts
┌───────▼──────────────── Java 后端 (Spring Boot 3.4.2) ─────────▼───────────────┐
│ 板块系统:BoardType 校验 · post 扩展字段 · tag/post_tag 二级筛选 · is_top 置顶   │
│ AI 桥接:PostAiIngestService(@Async afterCommit) · GraphRagBackend(HTTP 代理)  │
└──────┬──────────────────────────────────────────┬──────────────────────────────┘
       │ MySQL 8(post/topic/tag/post_tag)         │ HTTP :8001
┌──────▼──────────┐                      ┌─────────▼──────────── graphrag (FastAPI) ───────────┐
│ MySQL · Redis    │                      │ 06 VLM describe_image(qwen2.5vl) ── 读图            │
│ · MinIO(图片)   │                      │ 07 /ingest-post → Neo4j Post/Item + campus_post_vector│
└──────────────────┘                      │ 08 /match-posts → 意图识别 + 向量检索 + 图过滤        │
                                          └──────────┬──────────────────────────────────────────┘
                                                     │ 本地优先: qwen2.5(chat)·bge-m3(embed)·qwen2.5vl(VLM),失败降级云端
                                          ┌──────────▼──────────┐
                                          │ Neo4j 5 + Ollama    │
                                          └─────────────────────┘
```

## 六、公共数据模型概览

> 详细建表/字段见 [`01`](./01-板块分类体系-基础架构.md) 与 [`07`](./07-AI知识入库-Neo4j图谱.md),此处仅概览。

### MySQL(`campus_wall`)
| 对象 | 变更 |
|------|------|
| `topic` | 加 `code`(板块机器标识),顶级分组重映射为 5 板块 |
| `post` | 加 `price`/`salary`/`info_fee`/`contact`/`banner_object_name`/`is_top` |
| `tag`(新) | 标签字典,`board_code` 归属父板块 |
| `post_tag`(新) | 帖子-标签关联(替换 `ai_tags` LIKE,`ai_tags` 保留兼容) |
| Flyway | `V3.2__board_remap` · `V3.3__post_board_fields` · `V3.4__tag_tables`(幂等、版本递增) |

### Neo4j(`campus-wall-graphrag`)
| 对象 | 说明 |
|------|------|
| `(:Post)` | 帖子节点(`postId/intent/category/text/status`) |
| `(:Item)` | 物品节点(`description/embedding/color/brand/...`) |
| `(:Intent)`/`(:Category)`/`(:Tag)` | 意图/板块/标签节点 |
| 向量索引 `campus_post_vector` | `FOR (i:Item) ON i.embedding`,cosine,dim=1024(独立于现有 Chunk 索引) |

### 板块定义(权威表)
| code | 板块 | 必填 | 特殊 |
|------|------|------|------|
| `recommend` | 推荐 | — | 全量时间线、不可发布、`is_top` 优先 |
| `secondhand` | 二手交易 | 价格 | 联系方式可复制 |
| `parttime` | 兼职发布 | 薪资 | 信息费、联系方式 |
| `promotion` | 推广 | — | Banner + `[推广]` 标签 |
| `team` | 组队 | — | 头像叠放、不显示数字 |

## 七、实施顺序与里程碑

```
阶段一 · 板块系统
  01 基础架构(Flyway + BoardType + tag/post_tag + index/publish 骨架)   ← 必须最先
   └─> 02 二手 │ 03 兼职 │ 04 推广 │ 05 组队   (可并行,互不依赖)

阶段二 · AI 系统(可与阶段一部分并行,但 intent 依赖 category 映射,01 先行更顺)
  06 VLM 能力(describe_image + sanitize)   ← AI 必须最先
   └─> 07 知识入库(/ingest-post + Neo4j + @Async 触发)
        └─> 08 智能推荐(/match-posts + 帖子卡片 + 前端)
```

**建议里程碑**:M1 板块系统可用(01+02+03);M2 推广/组队(04+05);M3 AI 读图入库(06+07);M4 AI 推荐闭环(08)。
