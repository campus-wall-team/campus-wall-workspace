# 新人快速上手

欢迎加入校园墙项目！本文档将帮助你在 30 分钟内完成环境搭建并运行项目。

## 环境要求

| 工具 | 最低版本 | 用途 | 安装方式 |
|------|----------|------|----------|
| JDK | 17 | Java 后端开发 | [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) 或 [OpenJDK](https://adoptium.net/) |
| Maven | 3.8+ | Java 构建 | IDEA 内置 或 [官网下载](https://maven.apache.org/download.cgi) |
| Node.js | 18+ | 前端开发 | [官网下载](https://nodejs.org/) |
| Python | 3.12 | AI 服务开发 | [官网下载](https://www.python.org/downloads/) |
| Docker | 最新版 | 基础设施 | [Docker Desktop](https://www.docker.com/products/docker-desktop/) |
| Git | 最新版 | 版本控制 | [官网下载](https://git-scm.com/downloads) |
| IntelliJ IDEA | 最新版 | Java IDE | [官网下载](https://www.jetbrains.com/idea/download/) |
| VS Code | 最新版 | 前端/Python IDE | [官网下载](https://code.visualstudio.com/) |

**推荐配置**：
- 开发机内存：16GB+（同时运行多个服务 + Docker）
- 磁盘空间：50GB+（Docker 镜像、数据卷）

## 第一步：克隆代码

```bash
# 克隆主仓库（如果还有其他仓库，依次克隆）
git clone <仓库地址> campus_wall
git clone <仓库地址> campus-wall-frontend
git clone <仓库地址> campus-wall-monitor-ui
git clone <仓库地址> campus-wall-graphrag
git clone <仓库地址> campus-wall-data-pipeline
git clone <仓库地址> campus-wall-alert-adapter
git clone <仓库地址> campus-wall-ops
```

**建议目录结构**：
```
campus-wall-workspace/
├── campus_wall/                  # 主后端
├── campus-wall-frontend/         # 多端前端
├── campus-wall-monitor-ui/       # 管理后台
├── campus-wall-graphrag/         # AI 服务
├── campus-wall-data-pipeline/    # 数据管道
├── campus-wall-alert-adapter/    # 告警适配
├── campus-wall-ops/              # 运维配置
└── docs/                         # 本文档目录
```

## 第二步：启动基础设施（Docker）

所有数据库和中间件通过 Docker Compose 一键启动：

```bash
cd campus-wall-ops

# 复制环境变量模板（按需修改）
cp .env.example .env

# 启动所有基础设施服务
docker-compose up -d
```

**启动的服务**：
| 服务 | 端口 | 说明 |
|------|------|------|
| MySQL | 3306 | 主数据库 |
| Redis | 6379 | 缓存 |
| MinIO | 9000/9001 | 对象存储 |
| Neo4j | 7475/7688 | 知识图谱 |
| Chroma | 8000 | 向量数据库 |
| Prometheus | 9090 | 指标采集 |
| Grafana | 3000 | 可视化面板 |
| Alertmanager | 9093 | 告警管理 |
| Nginx | 8090 | 监控UI代理 |

**验证启动**：
```bash
# 查看所有容器状态
docker-compose ps

# 查看日志
docker-compose logs -f mysql
docker-compose logs -f redis
```

## 第三步：启动主后端服务 (campus_wall)

### 3.1 配置数据库

MySQL 首次启动后，数据库会自动通过 Flyway 迁移创建。检查数据库：

```bash
# 进入 MySQL 容器
docker exec -it campus-mysql mysql -uroot -p
# 密码在 .env 中，默认 123456

# 查看数据库
SHOW DATABASES;
USE campus_wall;
SHOW TABLES;
```

### 3.2 配置环境变量

```bash
cd campus_wall
cp .env.example .env
# 编辑 .env 文件，配置以下关键变量：
# - MySQL 连接信息
# - Redis 连接信息
# - MinIO 连接信息
# - 微信 AppID/AppSecret（如需微信登录）
# - DashScope API Key（如需 AI 功能）
```

### 3.3 启动服务

**方式一：IDEA 启动（推荐开发时使用）**
1. IDEA 打开 `campus_wall` 项目
2. 等待 Maven 依赖下载完成
3. 运行 `CampusWallBackendApplication.java`
4. 服务将启动在 `http://localhost:8080`

**方式二：命令行启动**
```bash
cd campus_wall
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

**验证启动**：
```bash
curl http://localhost:8080/actuator/health
# 预期返回：{"status":"UP"}
```

## 第四步：启动前端 (campus-wall-frontend)

```bash
cd campus-wall-frontend

# 安装依赖
npm install

# 启动 H5 开发服务器
npm run dev:h5
```

启动后，终端会显示访问地址（通常是 `http://localhost:5173` 或类似）。

**微信小程序开发**（如需）：
```bash
# 编译为微信小程序代码
npm run dev:mp-weixin

# 使用微信开发者工具打开 dist/dev/mp-weixin 目录
```

## 第五步：启动管理后台 (campus-wall-monitor-ui)

```bash
cd campus-wall-monitor-ui

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问地址通常为 `http://localhost:5174`。

## 第六步：启动 AI 服务 (campus-wall-graphrag) [可选]

AI 问答功能需要启动 GraphRAG 服务。

### 6.1 启动 Ollama（本地 Embedding）

```bash
# 安装 Ollama (https://ollama.com/)
# 拉取 bge-m3 模型
ollama pull bge-m3

# 启动 Ollama 服务（默认端口 11434）
ollama serve
```

### 6.2 启动 GraphRAG

**方式一：Docker（推荐）**
```bash
cd campus-wall-ops
docker-compose up -d graphrag
```

**方式二：本地 Python**
```bash
cd campus-wall-graphrag

# 创建虚拟环境
python -m venv .venv

# Windows
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env，配置 NEO4J_PASSWORD 和 LLM_API_KEY

# 启动服务
uvicorn app.main:app --host 0.0.0.0 --port 8001
```

**验证启动**：
```bash
curl http://localhost:8001/health
# 预期返回 Neo4j 连接状态
```

## 常用开发命令速查

### 后端 (campus_wall)

```bash
# 编译
mvn clean compile

# 运行测试
mvn test

# 打包
mvn clean package

# 运行（开发模式）
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

### 前端 (campus-wall-frontend)

```bash
# 安装依赖
npm install

# 开发模式（H5）
npm run dev:h5

# 开发模式（微信小程序）
npm run dev:mp-weixin

# 构建生产环境（H5）
npm run build:h5

# 类型检查
npm run type-check
```

### 管理后台 (campus-wall-monitor-ui)

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产环境
npm run build
```

### Docker Compose (campus-wall-ops)

```bash
# 启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f [服务名]

# 停止所有服务
docker-compose down

# 停止并删除数据卷（慎用）
docker-compose down -v

# 重启单个服务
docker-compose restart [服务名]

# 构建并启动
docker-compose up -d --build [服务名]
```

## 第一个开发任务建议

完成环境搭建后，可以尝试以下任务来熟悉项目：

### 推荐任务（按难度排序）

1. **修改一个 API 接口响应格式**
   - 文件：`campus_wall/src/main/java/com/jyu/campus/community/controller/PostController.java`
   - 目标：在帖子列表接口中增加一个字段

2. **前端添加一个新页面**
   - 参考现有页面在 `campus-wall-frontend/src/pages/` 下创建
   - 在 `pages.json` 中注册路由

3. **修改 Grafana 面板**
   - 访问 http://localhost:3000
   - 编辑或导入新面板

4. **运行数据管道**
   - 参考 `campus-wall-data-pipeline/README.md`
   - 尝试 dry-run 模式提取数据
