## 服务职责划分

### 1. campus_wall（主后端服务）
**定位**：核心业务后端，所有客户端请求的入口
**职责**：
- 用户认证（微信 OAuth2 + JWT）
- 帖子 CRUD、评论、点赞、收藏
- 分类管理、搜索
- AI 聊天代理（转发到 GraphRAG）
- 内容审核（敏感词 + AI 复审）
- 私信系统（WebSocket）
- 管理后台 API
- 定时任务（指标收集、文件清理）

### 2. campus-wall-frontend（多端前端）
**定位**：面向学生的移动端应用
**职责**：
- 帖子浏览与发布
- AI 学长聊天界面
- 私信聊天
- 用户个人中心
- 支持 H5 和微信小程序

### 3. campus-wall-monitor-ui（管理后台）
**定位**：面向管理员的后台管理系统
**职责**：
- 登录认证
- 内容审核队列
- 数据统计概览
- Grafana 面板嵌入

### 4. campus-wall-graphrag（AI 知识图谱服务）
**定位**：AI 问答核心引擎
**职责**：
- 接收文档并构建知识图谱（/index）
- 接收问题并返回 AI 回答（/query）
- Neo4j 知识图谱维护
- 向量索引管理

### 5. campus-wall-data-pipeline（数据管道）
**定位**：ETL 数据处理器
**职责**：
- 从 campus_wall MySQL 提取帖子数据
- 数据清洗（去噪、去广告）
- 数据脱敏（PII 信息移除）
- 推送到 GraphRAG 构建知识图谱

### 6. campus-wall-alert-adapter（告警适配器）
**定位**：告警通知转发服务
**职责**：
- 接收 Alertmanager 的 webhook 告警
- 转换为企微/钉钉消息格式
- 发送到对应的群聊

### 7. campus-wall-ops（运维配置）
**定位**：基础设施即代码
**职责**：
- Docker Compose 编排所有基础设施服务
- Prometheus 监控配置
- Grafana 面板配置
- Alertmanager 告警规则
- Nginx 反向代理配置

## 服务间通信关系

| 调用方 | 被调用方 | 协议 | 用途 |
|--------|----------|------|------|
| 前端 (H5/小程序) | campus_wall | HTTP REST | 所有业务请求 |
| 前端 (H5/小程序) | campus_wall | WebSocket | 实时私信 |
| campus_wall | campus-wall-graphrag | HTTP REST | AI 问答 |
| campus_wall | MySQL | JDBC | 业务数据存储 |
| campus_wall | Redis | Redis 协议 | 缓存/会话 |
| campus_wall | MinIO | S3 API | 图片存储 |
| data-pipeline | MySQL | pymysql | 数据提取 |
| data-pipeline | campus-wall-graphrag | HTTP POST /index | 推送知识 |
| graphrag | Neo4j | Bolt | 知识图谱存储 |
| graphrag | Ollama (host) | HTTP | Embedding |
| graphrag | DashScope | HTTP | Chat LLM |
| Alertmanager | alert-adapter | HTTP webhook | 告警通知 |
| Prometheus | campus_wall | HTTP /actuator/prometheus | 指标采集 |
| Prometheus | node/redis/mysql/blackbox exporter | HTTP | 指标采集 |
| Grafana | Prometheus | HTTP | 数据源 |
| Nginx | campus_wall | HTTP | API 反向代理 |
| Nginx | Grafana | HTTP | 面板代理 |
| monitor-ui | campus_wall | HTTP | 管理 API |

## 外部依赖

| 外部服务 | 用途 | 调用方 |
|----------|------|--------|
| 微信开放平台 | 用户 OAuth2 登录 | campus_wall |
| DashScope（阿里云） | Chat LLM (qwen-plus) | campus-wall-graphrag |
| Ollama（本地部署） | Embedding (bge-m3) | campus-wall-graphrag |

## 部署拓扑

### 开发环境（单机）
```
[一台开发机]
  ├── campus_wall (本地启动，端口 8080)
  ├── campus-wall-frontend (npm run dev:h5，端口随 Vite 分配)
  ├── campus-wall-monitor-ui (npm run dev，端口随 Vite 分配)
  ├── campus-wall-graphrag (本地 Python 或 Docker)
  ├── campus-wall-ops/docker-compose.yml (所有基础设施容器)
  │     ├── MySQL :3306
  │     ├── Redis :6379
  │     ├── MinIO :9000/9001
  │     ├── Neo4j :7475/7688
  │     ├── Prometheus :9090
  │     ├── Grafana :3000
  │     └── ...
  └── Ollama (本地，端口 11434)
```

### 生产环境（建议）
```
[负载均衡 / CDN]
       │
  [Nginx 网关]
       │
   ┌───┴───┐
   │       │
[App 1] [App 2]  campus_wall (多实例)
   │       │
   └───┬───┘
       │
   [共享存储]

```
