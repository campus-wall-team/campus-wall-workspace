## 整体架构概览

## 服务职责划分

### 1. campus_wall（主后端服务）
**定位**：核心业务后端，所有客户端请求的入口
**职责**：
- 用户认证（微信 OAuth2 + JWT）；学生认证（学生证 OCR + 人工复核）
- 帖子 CRUD、评论、点赞、收藏；5 板块（推荐/二手/兼职/推广/组队）+ 标签 + 排行榜/热搜榜
- AI 学长 Agent（单一入口 `/api/v1/ai-senior/agent`，Planner-Executor + RelevanceJudge，调 GraphRAG）
- 内容审核（敏感词 + AI 复审）
- 私信系统（WebSocket）
- 管理后台 API（独立 admin_user RBAC、操作审计、运营看板、系统配置）
- 定时任务（指标收集、文件清理）

### 2. campus-wall-frontend（多端前端）
**定位**：面向学生的移动端应用
**职责**：
- 帖子浏览与发布
- AI 学长聊天界面
- 私信聊天
- 用户个人中心
- 支持 H5 和微信小程序

### 3. campus-wall-monitor-ui（管理后台）
**定位**：面向管理员的后台管理系统
**职责**：
- 登录认证 + RBAC 权限驱动菜单（Pinia useUserStore + v-permission 指令 + 路由 meta.perms 守卫）
- 内容审核队列、举报处理、意见反馈、学生认证复核
- 用户管理（封禁/解封）、管理员/角色权限管理、系统配置
- 操作审计日志查询
- 运营看板（KPI 卡 + 趋势/分布/热帖图表，vue-echarts）
- 系统监控概览 + Grafana 面板嵌入

### 4. campus-wall-ai（AI 知识图谱服务）

> 原独立服务 campus-wall-graphrag 已并入 campus-wall-ai（端口 8011），下列全部 HTTP 端点路径原样保留。

**定位**：AI 问答核心引擎（9 个 HTTP 端点）
**职责**：
- 接收文档并构建知识图谱（/index）
- 接收问题并返回 AI 回答（/query + /query/stream 流式）
- 帖子入图谱（/ingest-post，含 VLM 图片描述 + PII 脱敏）
- 自然语言匹配帖子（/match-posts，向量召回 + 匹配理由）
- 多模态读图（/describe-image，VLM qwen2.5vl:7b）
- 文档/帖子管理（/documents、DELETE /posts/{id}）、健康检查（/health）
- Neo4j 知识图谱维护与原生向量索引管理（campus_chunk_vector + campus_post_vector）
- LLM 本地优先（Ollama qwen2.5:7b）+ 云端 DashScope 降级

### 5. campus-wall-data-pipeline（数据管道）
**定位**：ETL 数据处理器
**职责**：
- 从 campus_wall MySQL 提取帖子数据
- 数据清洗（去噪、去广告）
- 数据脱敏（PII 信息移除）
- 推送到 campus-wall-ai（端口 8011）构建知识图谱

### 6. campus-wall-alert-adapter（告警适配器）
**定位**：告警通知转发服务
**职责**：
- 接收 Alertmanager 的 webhook 告警
- 转换为企微/钉钉消息格式
- 发送到对应的群聊

### 7. campus-wall-ops（运维配置）
**定位**：基础设施即代码
**职责**：
- Docker Compose 编排所有基础设施服务
- Prometheus 监控配置
- Grafana 面板配置
- Alertmanager 告警规则
- Nginx 反向代理配置

## 服务间通信关系

| 调用方 | 被调用方 | 协议 | 用途 |
|--------|----------|------|------|
| 前端 (H5/小程序) | campus_wall | HTTP REST | 所有业务请求 |
| 前端 (H5/小程序) | campus_wall | WebSocket | 实时私信 |
| campus_wall | campus-wall-ai | HTTP REST | AI 问答 |
| campus_wall | MySQL | JDBC | 业务数据存储 |
| campus_wall | Redis | Redis 协议 | 缓存/会话 |
| campus_wall | MinIO | S3 API | 图片存储 |
| data-pipeline | MySQL | pymysql | 数据提取 |
| data-pipeline | campus-wall-ai | HTTP POST /index | 推送知识 |
| campus-wall-ai | Neo4j | Bolt | 知识图谱存储 + 向量索引 |
| campus-wall-ai | Ollama (host) | HTTP | Chat / Embedding / VLM（本地优先） |
| campus-wall-ai | DashScope | HTTP | Chat / VLM 云端降级（兜底） |
| Alertmanager | alert-adapter | HTTP webhook | 告警通知 |
| Prometheus | campus_wall | HTTP /actuator/prometheus | 指标采集 |
| Prometheus | node/redis/mysql/blackbox exporter | HTTP | 指标采集 |
| Grafana | Prometheus | HTTP | 数据源 |
| Nginx | campus_wall | HTTP | API 反向代理 |
| Nginx | Grafana | HTTP | 面板代理 |
| monitor-ui | campus_wall | HTTP | 管理 API |

## 外部依赖

| 外部服务 | 用途 | 调用方 |
|----------|------|--------|
| 微信开放平台 | 用户 OAuth2 登录 | campus_wall |
| Ollama（本地部署，主） | Chat (qwen2.5:7b / 内网 Qwen3.6-35B)、Embedding (bge-m3)、VLM (qwen2.5vl:7b) | campus-wall-ai |
| DashScope（阿里云，兜底） | Chat (qwen-plus)、VLM (qwen-vl-plus) 云端降级 | campus-wall-ai |

## 部署拓扑

### 开发环境（单机）
```
[一台开发机]
  ├── campus_wall (本地启动，端口 8080)
  ├── campus-wall-frontend (npm run dev:h5，端口随 Vite 分配)
  ├── campus-wall-monitor-ui (npm run dev，端口随 Vite 分配)
  ├── campus-wall-ai (端口 8011，本地 Python 或 Docker；原 campus-wall-graphrag 已并入)
  ├── campus-wall-ops/docker-compose.yml (所有基础设施容器)
  │     ├── MySQL :3306
  │     ├── Redis :6379
  │     ├── MinIO :9000/9001
  │     ├── Neo4j :7475/7688
  │     ├── Prometheus :9090
  │     ├── Grafana :3000
  │     └── ...
  └── Ollama (本地，端口 11434)
```

