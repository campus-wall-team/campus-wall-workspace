## 技术选型理由

### 为什么选择 Java + Spring Boot？
- 团队熟悉度高，生态成熟
- Spring AI 提供标准化的 LLM 集成方案
- 丰富的监控和运维工具链

### 为什么选择 uni-app？
- 一套代码支持 H5 + 微信小程序等多端
- Vue 3 生态，学习成本低
- 适合校园场景（学生主要使用微信小程序）

### 为什么选择 GraphRAG？
- 知识图谱能更好地表达实体关系
- 结合向量检索，问答更准确
- Neo4j 官方支持 GraphRAG

### 为什么选择双 LLM 架构？
- Chat LLM（云端）：推理能力强，用于问答生成
- Embedding LLM（本地）：成本低、延迟低，用于向量化
- 解耦后可根据需求独立替换
