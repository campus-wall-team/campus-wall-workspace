## 技术选型理由

### 为什么选择 Java + Spring Boot？
- 团队熟悉度高，生态成熟
- Spring AI 提供标准化的 LLM 集成方案
- 丰富的监控和运维工具链

### 为什么选择 uni-app？
- 一套代码支持 H5 + 微信小程序等多端
- Vue 3 生态，学习成本低
- 适合校园场景（学生主要使用微信小程序）

### 为什么选择 GraphRAG？
- 知识图谱能更好地表达实体关系
- 结合向量检索，问答更准确
- Neo4j 官方支持 GraphRAG

### 为什么选择本地优先 + 云端降级的多模型架构？
- **本地优先**：Chat（qwen2.5:7b / 内网 Qwen3.6-35B）、Embedding（bge-m3）、VLM（qwen2.5vl:7b）均以本地 Ollama 为主，成本低、延迟低、数据不出内网
- **云端降级**：本地不可用时自动 failover 到 DashScope（qwen-plus / qwen-vl-plus），保障可用性（`_with_fallback`）
- **多模态**：VLM 角色让"发帖读图"成为可能，图片描述与文本一并入图谱被检索
- 三套角色解耦，可按需独立替换主/兜底模型
