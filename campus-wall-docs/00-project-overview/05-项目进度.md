### 1. `campus_wall` — Java 核心后端

**总体：✅ 完成** ｜ 核心功能基本完成，仅 Redis 迁移为 mock、logout 未接通遗留

> Campus Wall 后端为 Spring Boot 3.4.2（Java 17、Spring AI 1.0.8 GA）单体应用，涵盖用户认证、社交关注、帖子社区（5 大板块分类）、评论互动、AI学长助手（已收口为单一 agent 入口）、内容审核、管理端独立 RBAC 鉴权、运营看板、系统配置、排行榜、学生认证、文件上传等核心功能。Flyway 迁移已重置为 V3.0~V4.4 共 15 个脚本、约 37 张表；RedisMigrationService 仍含 4 个 TODO 占位符（实现为 mock 数据）。
>
> **重大变更（06-15）**：① AI 已收口为**单一入口 `POST /api/v1/ai-senior/agent`**（AgentController，强制 `@RequestAttribute("userId")` JWT 鉴权，轻量 Planner-Executor + RelevanceJudge 反幻觉判定），旧 `/ai-senior/chat`、`/chat/stream` 已下线；② 管理端落地**独立 admin_user RBAC 体系**（5 张 RBAC 表 + 3 预置角色 superadmin/moderator/viewer，`@RequirePermission` 权限码鉴权），不再依赖 C 端 User.role，管理端登录迁至 AdminAuthController。
