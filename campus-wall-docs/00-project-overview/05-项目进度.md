## 1. 当前可运行的 Demo（全栈 AI 学长链路）

最小可跑通的核心是 **GraphRAG「AI 学长」离线问答**，并已打通到 Java 后端的完整链路。它是后续扩展其它模块的地基。

```
小程序 API → 后端 :8080 /api/v1/ai-senior/chat → GraphRAG :8001 /query
           → bge-m3 向量化 → Neo4j 向量检索 Top-K → 图遍历补充事实
           → qwen2.5 生成答案 → 回传（带来源引用）
```

### 1.1 验证结果（2026-06-04）

| 环节 | 状态 | 证据 |
|------|------|------|
| 基础设施（MySQL/Redis/Neo4j/MinIO + 监控栈） | ✅ | `docker ps` 全部 Up |
| GraphRAG `:8001` | ✅ | `/health` → `{"status":"ok","neo4j":true}`；16 篇知识入库 |
| 知识问答（直连 GraphRAG） | ✅ | 「四级多少分报六级」→「四级425分以上」+ 来源 |
| Java 后端 `:8080` | ✅ | `/actuator/health` → `{"status":"UP"}`；Flyway 迁移至 v2.1 |
| **全栈链路**（后端 → GraphRAG） | ✅ | `/api/v1/ai-senior/chat` 带 JWT 返回 `code:200` + 答案 + 5 条来源；GraphRAG 侧观察到对应 `/query` |

### 1.2 启动方式

GraphRAG demo 启动、灌库、问答的完整步骤见 [`demo/README.md`](../../demo/README.md)。后端与全栈见 [`PROJECT.md` §9](../../PROJECT.md)。要点：

```bash
# 1) GraphRAG（离线本地）
cp demo/.env.example demo/.env          # 填 NEO4J_PASSWORD
nohup bash demo/run-graphrag.sh >> demo/logs/graphrag.log 2>&1 & disown
python3 demo/seed.py                     # 幂等灌库

# 2) Java 后端（已有构建产物 target/*.jar）
cd campus_wall && java -jar target/campus-wall-0.0.1-SNAPSHOT.jar
```

> Demo 期间踩到的两个**本地环境**坑（已修，不影响代码仓库）：
> - 后端 `.env` 里 `characterEncoding=utf8mb4` 不是合法 Java 字符集 → 应为 `utf8`（提交版 `.env.example` 已正确）。
> - Flyway 历史表里 `V1.0` 曾被记为失败 → 标记为成功后，`V2.1`（custom_emoji）正常补跑。

## 3. 各模块状态详情

### 3.1 `campus_wall` — Java 后端　✅
- **已完成**：用户/关注/帖子/评论/分类搜索/浏览历史/私信通知/AI 学长/AI 偏好/管理审核/文件上传/反馈 等 18 个 Controller；Flyway 迁移（V1.0 + V2.1）；多级 Redis 缓存；WebSocket 私信；统一 `Result<T>` 响应与 JWT 鉴权。
- **未完成 / TODO**：
  - `admin/service/RedisMigrationService.java`：点赞/收藏/搜索/帖子迁移目前为 **mock 占位脚本**，实际 Mapper 注入被注释。
  - `admin/controller/AdminModerationController.java`：`User` 实体缺 `role` 字段，暂以「登录即管理员」兜底，**角色权限体系待补**。

### 3.2 `campus-wall-frontend` — 微信小程序　✅
- **已完成**：5 个 Tab、30+ 页面、共享组件、`community/social/ai/admin` API 封装、请求层 JWT 注入、WebSocket 心跳与重连。无 TODO/FIXME。
- **未完成 / 备注**：小程序需在微信开发者工具中运行（无法无头启动）；`.env.development` 的 `VITE_API_BASE_URL` 需指向后端可达地址。

### 3.3 `campus-wall-graphrag` — GraphRAG 引擎　✅
- **已完成**：FastAPI + Neo4j 知识图谱 + 原生向量索引；双 LLM（Chat 抽取/生成、Embedding 向量化）；`/health /index /query /documents` 全实现且幂等 upsert。
- **未完成 / 备注**：无功能缺口。`app/config.py` 中 `NEO4J_PASSWORD` 有开发默认值（建议后续也外置）。

### 3.4 `campus-wall-data-pipeline` — 数据管道　✅
- **已完成**：`clean → desensitize → KnowledgeUnit → /index` 全流程；脱敏覆盖手机号/身份证/学号等；默认 dry-run，`--push` 才入库。
- **未完成 / 备注**：无功能缺口；合规前提（授权、本机导出）需人工保证。

### 3.5 `campus-wall-alert-adapter` — 告警转发　✅

### 3.6 `campus-wall-monitor-ui` — 运营后台　🟡

- **未完成 / TODO**：`src/config.js` 中 Grafana 看板 **UID/panelId 为占位值**，待 ops 提供真实看板 UID 后改配置重新 build。

### 3.7 `campus-wall-ops` — 编排与监控　✅
