## 1. 各模块功能清单

### 1. `campus_wall` — Java 核心后端

**总体：✅ 完成** ｜ ✅完成 96 · 🟡部分完成 5 · ⬜未完成 1

> Campus Wall 后端为 Spring Boot 3.3.7 单体应用，18个 Controller 共 91个接口 + 1个 WebSocket endpoint，涵盖用户认证、社交关注、帖子社区、评论互动、AI学长助手、内容审核、文件上传等核心功能。Flyway 迁移包含 V1.0 初始化和 V2.1 Emoji 表；RedisMigrationService 包含 4 个 TODO 占位符（实现为 mock 数据）；AdminModerationController 缺失 User.role 字段的鉴权（当前仅依赖 JWT 登录）；AI 相关接口无 @RequestAttribute("userId") 绑定，从 DTO 或参数直接获取 userId，存在跨用户风险。
