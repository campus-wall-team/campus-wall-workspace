**新增模块规范**：
1. 在 `com.jyu.campus` 下创建新包（如 `market`）
2. 包内结构：`controller/` → `service/` → `mapper/` → `entity/`
3. Controller 类名后缀为 `Controller`，路径前缀为 `/api/v1/模块名`
4. Service 接口名后缀为 `Service`，实现类后缀为 `ServiceImpl`
5. Mapper 接口继承 `BaseMapper<Entity>`
6. Entity 类对应数据库表，使用 `@TableName` 注解

## campus-wall-ai（AI 服务，原 campus-wall-graphrag 已并入，端口 8011）

> 原 campus-wall-graphrag 独立服务已并入 campus-wall-ai（FastAPI 单服务，端口 8011）。原 graphrag 的全部 HTTP 契约端点（`/query` `/query/stream` `/index` `/ingest-post` `/match-posts` `/documents` `DELETE /posts/{id}` `/health`）原样保留在 `campus-wall-ai/app/main.py`，图谱/向量/LLM/脱敏代码迁入 `campus-wall-ai/app/graphrag/`。

```
campus-wall-ai/
├── app/
│   ├── __init__.py
│   ├── main.py                       # FastAPI 应用入口（保留原 graphrag 全部 HTTP 契约端点）
│   ├── graphrag/                     # 迁入：图谱/向量/LLM/脱敏
│   │   ├── config.py                 # 环境配置
│   │   ├── graph_store.py            # Neo4j 图存储
│   │   └── llm.py                    # LLM 客户端
│   └── ...                           # AI v2（LangGraph 子图等）
│
├── Dockerfile
├── requirements.txt
├── .env.example
└── README.md
```

**新增模块规范**：
1. 在 `app/` 下创建新模块文件
2. 在 `app/main.py` 中注册新路由
3. 复杂逻辑应拆分为独立模块

## 新增文件检查清单

在任何仓库新增文件时，请确认：

- [ ] 文件放置在正确的目录下
- [ ] 文件名符合命名规范
- [ ] 同类文件保持一致的目录深度
- [ ] 不在根目录随意创建文件（统一放入对应目录）
