# 开发规范

本文档规定校园墙项目的开发规范，所有开发者必须遵守。

## Git 规范

### 分支模型

采用简化版 Git Flow：

```
main
  │
  ├── feature/user-profile      # 功能分支
  ├── feature/ai-chat
  ├── hotfix/login-bug          # 热修复分支
  └── refactor/post-service     # 重构分支
```

| 分支类型 | 命名规则 | 说明 |
|----------|----------|------|
| 主分支 | `main` | 稳定版本，可直接部署 |
| 功能分支 | `feature/功能描述` | 新功能开发，从 main 切出 |
| 热修复 | `hotfix/问题描述` | 紧急修复，从 main 切出 |
| 重构 | `refactor/重构描述` | 代码重构，从 main 切出 |

### Commit Message 规范

采用 [Conventional Commits](https://www.conventionalcommits.org/) 规范：

```
<type>(<scope>): <subject>

<body>

<footer>
```

**Type 类型**：

| 类型 | 说明 | 示例 |
|------|------|------|
| `feat` | 新功能 | `feat(ai): 添加AI学长多轮对话` |
| `fix` | 修复 bug | `fix(auth): 修复JWT过期不刷新` |
| `docs` | 文档更新 | `docs: 更新API接口文档` |
| `style` | 代码格式 | `style: 统一缩进为4空格` |
| `refactor` | 重构 | `refactor(post): 重构帖子服务层` |
| `perf` | 性能优化 | `perf(cache): 优化Redis缓存策略` |
| `test` | 测试 | `test: 添加用户登录单元测试` |
| `chore` | 构建/工具 | `chore: 升级Spring Boot到3.3.7` |
| `ci` | CI/CD | `ci: 添加GitHub Actions工作流` |

**Scope 范围**（按仓库定义）：

**campus_wall**：
- `auth` - 认证授权
- `post` - 帖子模块
- `comment` - 评论模块
- `user` - 用户模块
- `ai` - AI模块
- `admin` - 管理模块
- `ws` - WebSocket
- `config` - 配置

**campus-wall-frontend**：
- `page/页面名` - 具体页面
- `component/组件名` - 具体组件
- `api` - 接口层
- `utils` - 工具函数

**示例**：
```bash
feat(post): 添加帖子置顶功能

- 新增 post.is_pinned 字段
- 置顶帖子在列表中优先展示
- 管理员可在后台操作置顶

Closes #123

fix(ai): 修复AI问答超时问题

将HTTP超时时间从10s调整为30s，避免长回答被截断。

docs: 更新部署文档

补充Docker Compose内存限制说明。
```

## 代码规范

### Java (campus_wall)

#### 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 包名 | 全小写，点分隔 | `com.jyu.campus.community` |
| 类名 | 大驼峰 | `PostService`, `UserController` |
| 接口名 | 大驼峰，可接 `I` 前缀 | `IPostService` 或 `PostService` |
| 方法名 | 小驼峰 | `getPostById()`, `createPost()` |
| 变量名 | 小驼峰 | `postList`, `userId` |
| 常量 | 全大写，下划线分隔 | `MAX_PAGE_SIZE`, `DEFAULT_TTL` |
| 数据库表 | 小写，下划线分隔 | `post`, `user_follow` |
| 数据库字段 | 小写，下划线分隔 | `create_time`, `is_deleted` |

#### 代码格式

- **缩进**：4 个空格（禁止使用 Tab）
- **行宽**：120 字符
- **花括号**：K&R 风格，左花括号不换行

```java
// 正确
public class PostService {
    public Post getPostById(Long id) {
        if (id == null || id <= 0) {
            throw new IllegalArgumentException("Invalid post id");
        }
        return postMapper.selectById(id);
    }
}

// 错误
public class PostService
{
    public Post getPostById(Long id)
    {
        if(id==null)
        {
            // ...
        }
    }

```

#### 注释规范

```java
/**
 * 获取帖子详情，带缓存
 *
 * @param id 帖子ID
 * @return 帖子详情，不存在返回null
 */
public Post getPostById(Long id) {
    // 从缓存获取
    String cacheKey = "post:" + id;
    Post post = (Post) redisTemplate.opsForValue().get(cacheKey);

    if (post != null) {
        return post; // 缓存命中
    }

    // 缓存未命中，查数据库
    post = postMapper.selectById(id);

    if (post != null) {
        redisTemplate.opsForValue().set(cacheKey, post, Duration.ofMinutes(30));
    }

    return post;
}
```

#### 分层规范

```
Controller (控制层)
    │
    ├── 接收 HTTP 请求
    ├── 参数校验 (@Valid)
    ├── 调用 Service
    └── 返回统一响应 Result<T>
    │
Service (服务层)
    │
    ├── 业务逻辑处理
    ├── 调用 Mapper / 其他 Service
    ├── 事务管理 (@Transactional)
    └── 缓存操作
    │
Mapper (数据层)
    │
    ├── 继承 BaseMapper
    ├── 复杂查询使用 @Select 注解或 XML
    └── 返回 Entity
    │
Entity (实体层)
    │
    ├── 对应数据库表
    ├── 使用 Lombok @Data
    └── 字段使用驼峰命名（MyBatis-Plus 自动映射）
```

#### 异常处理规范

```java
// 统一响应格式
@Data
public class Result<T> {
    private Integer code;
    private String message;
    private T data;

    public static <T> Result<T> success(T data) {
        return new Result<>(200, "success", data);
    }

    public static <T> Result<T> error(String message) {
        return new Result<>(500, message, null);
    }
}

// Controller 层统一异常处理
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public Result<Void> handleBusinessException(BusinessException e) {
        log.warn("业务异常: {}", e.getMessage());
        return Result.error(e.getMessage());
    }

    @ExceptionHandler(Exception.class)
    public Result<Void> handleException(Exception e) {
        log.error("系统异常", e);
        return Result.error("系统繁忙，请稍后重试");
    }
}
```

#### Vue 3 组件规范

```vue
<script setup lang="ts">
// 1. 导入（按类型分组）
import { ref, computed, onMounted } from 'vue'
import type { Post } from '@/types'
import { usePostFeed } from '@/composables/usePostFeed'
import PostCard from '@/components/PostCard.vue'

// 2. 类型定义
interface Props {
    categoryId?: number
}

// 3. Props / Emits
const props = withDefaults(defineProps<Props>(), {
    categoryId: 0
})

const emit = defineEmits<{
    (e: 'refresh'): void
}>()

// 4. 组合式函数
const { posts, loading, loadMore } = usePostFeed(props.categoryId)

// 5. 响应式状态
const currentPage = ref(1)
const hasMore = computed(() => posts.value.length >= currentPage.value * 10)

// 6. 方法
async function handleLoadMore() {
    currentPage.value++
    await loadMore(currentPage.value)
}

// 7. 生命周期
onMounted(() => {
    loadMore(1)
})
</script>

<template>
    <view class="post-list">
        <post-card
            v-for="post in posts"
            :key="post.id"
            :post="post"
        />
        <view v-if="hasMore" class="load-more" @click="handleLoadMore">
            {{ loading ? '加载中...' : '加载更多' }}
        </view>
    </view>
</template>

<style scoped lang="scss">
.post-list {
    padding: 16px;

    .load-more {
        text-align: center;
        color: #999;
        padding: 12px;
    }
}
</style>
```

### Python (AI 服务)

#### 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 模块/包 | 小写，下划线分隔 | `graph_store`, `llm_client` |
| 类名 | 大驼峰 | `Neo4jStore`, `OpenAILLM` |
| 函数/变量 | 小写，下划线分隔 | `search_chunks`, `query_vector` |
| 常量 | 全大写 | `DEFAULT_PORT`, `EMBED_DIM` |

#### 代码格式

```python
# 正确
class Neo4jStore:
    """Neo4j 知识图谱存储接口."""

    def __init__(self, uri: str, user: str, password: str) -> None:
        self._driver = GraphDatabase.driver(uri, auth=(user, password))

    def search(
        self,
        query_vector: list[float],
        top_k: int = 5,
    ) -> list[dict]:
        """向量检索相似文档块."""
        cypher = """
            CALL db.index.vector.queryNodes($index, $k, $vector)
            YIELD node, score
            RETURN node.text AS text, score
            ORDER BY score DESC
        """
        with self._driver.session() as session:
            result = session.run(cypher, index="chunk-index", k=top_k, vector=query_vector)
            return [record.data() for record in result]


# 错误
class neo4jstore:
    def __init__(self,uri,user,password):
        self.driver=GraphDatabase.driver(uri,auth=(user,password))
```

- [ ] 代码符合命名规范

- [ ] 无硬编码密钥/密码（使用环境变量）
