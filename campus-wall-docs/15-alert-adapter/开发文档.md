# campus-wall-alert-adapter 开发文档

## 项目简介

campus-wall-alert-adapter 是校园墙项目的告警通知转发服务。它接收来自 Prometheus Alertmanager 的 webhook 告警，将告警信息格式化为 Markdown 消息，通过企业微信或钉钉的群机器人发送到对应的告警群。

**设计特点**：
- 单文件微服务，轻量简洁
- 即使 webhook 未配置也不会崩溃
- 支持多渠道（企微/钉钉）

## 开发环境搭建

### 1. 环境要求

- Python 3.12
- pip

### 2. 安装依赖

```bash
cd campus-wall-alert-adapter

# 创建虚拟环境
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Linux / macOS

# 安装依赖
pip install -r requirements.txt
```

### 3. 配置环境变量

```bash
cp .env.example .env
```

编辑 `.env`：

```env
# 告警 Webhook 地址（企业微信或钉钉）
ALERT_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx

# 告警渠道：wecom（企业微信）或 dingtalk（钉钉）
ALERT_CHANNEL=wecom
```

### 4. 启动服务

```bash
# 本地开发
uvicorn app:app --host 0.0.0.0 --port 9094 --reload

# 或
python -m uvicorn app:app --host 0.0.0.0 --port 9094
```

## API 端点

### POST /alert

接收 Alertmanager webhook 告警。

**请求格式**（Alertmanager 标准格式）：

```json
{
  "version": "4",
  "groupKey": "{alertname=\"ServiceDown\"}",
  "status": "firing",
  "receiver": "webhook",
  "alerts": [
    {
      "status": "firing",
      "labels": {
        "alertname": "ServiceDown",
        "job": "campus-wall",
        "severity": "critical"
      },
      "annotations": {
        "summary": "服务 campus-wall 宕机",
        "description": "服务 campus-wall 在 5 分钟内不可达"
      },
      "startsAt": "2024-01-01T00:00:00Z"
    }
  ]
}
```

**企微/钉钉消息格式**（实际由 `build_markdown` 生成）：

一级标题汇总本批告警条数，每条告警一行加 blockquote 明细：

```markdown
## 🚨 校园墙监控告警 (1)

🔴 **ServiceDown** [critical | firing]
> 服务 campus-wall 宕机
> 服务 campus-wall 在 5 分钟内不可达
> job=`campus-wall` instance=`host.docker.internal:8011`
> 时间: 2026-06-15 08:00:00
```

结构说明：
- 标题 `## 🚨 校园墙监控告警 (N)`，N 为本批告警数；当 `status=resolved` 时标题变为 `## ✅ 校园墙告警恢复 (N)`。
- 每条告警一行：`<级别emoji> **<alertname>** [<severity> | <status>]`。
- 紧跟若干 blockquote 行：`> summary`、`> description`、`> job=... instance=...`、`> 时间: ...`（缺失字段自动省略）。
- 级别 emoji：🔴 critical / 🟠 warning / 🔵 info / ⚪ 其它。

### GET /health

健康检查端点。

**响应**：
```json
{
  "status": "ok",
  "channel": "wecom",
  "webhook_configured": true
}
```

- `channel`：当前 `ALERT_CHANNEL`（`wecom` / `dingtalk`）。
- `webhook_configured`：`ALERT_WEBHOOK` 是否已配置（布尔）。

### GET /

根端点，返回服务信息与可用端点。

**响应**：
```json
{
  "service": "campus-alert-adapter",
  "endpoints": ["/alert", "/health"]
}
```

## 告警渠道配置

### 企业微信

1. 在企微群中添加「群机器人」
2. 复制 webhook 地址
3. 配置环境变量：
```env
ALERT_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx
ALERT_CHANNEL=wecom
```

### 钉钉

1. 在钉钉群中添加「自定义机器人」
2. 复制 webhook 地址
3. 配置环境变量：
```env
ALERT_WEBHOOK=https://oapi.dingtalk.com/robot/send?access_token=xxxxxxxx
ALERT_CHANNEL=dingtalk
```

## Docker 部署

```bash
# 构建镜像
docker build -t campus-alert-adapter .

# 运行容器
docker run -d \
  -p 9094:9094 \
  -e ALERT_WEBHOOK=your_webhook_url \
  -e ALERT_CHANNEL=wecom \
  campus-alert-adapter
```

或通过 Docker Compose：
```bash
cd campus-wall-ops
docker-compose up -d alert-adapter
```

## Alertmanager 配置

在 `campus-wall-ops/alertmanager/alertmanager.yml` 中配置 webhook 接收器：

```yaml
receivers:
  - name: 'webhook'
    webhook_configs:
      - url: 'http://campus-alert-adapter:9094/alert'
        send_resolved: true
```

## 常见问题

### Q: 没有收到告警消息？

1. 检查 `ALERT_WEBHOOK` 是否配置正确
2. 检查 `ALERT_CHANNEL` 是否与 webhook 类型匹配
3. 检查 Alertmanager 配置是否正确指向该服务
4. 查看服务日志：`docker-compose logs -f alert-adapter`

### Q: 企微/钉钉发送失败？

1. 检查 webhook URL 是否有效（可在浏览器中访问测试）
2. 检查机器人是否被删除或禁用
3. 检查消息格式是否符合对应平台要求

### Q: 告警风暴？

在 Alertmanager 配置中设置告警分组和抑制规则：

```yaml
route:
  group_by: ['alertname', 'job']
  group_wait: 30s
  group_interval: 5m
  repeat_interval: 4h
```
