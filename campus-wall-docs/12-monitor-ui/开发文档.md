# campus-wall-monitor-ui 开发文档

## 项目简介

campus-wall-monitor-ui 是校园墙项目的管理员后台系统，面向运营和管理人员，提供内容审核、数据统计、系统监控等功能。基于 Vue 3 + Element Plus 开发，为桌面浏览器优化。

## 技术栈

| JavaScript | ES2020+ | 开发语言 |

| Element Plus | 2.8.4 | UI 组件库 |
| Vue Router | 4.4.5 | 路由管理 |
| Pinia | 2.2.2 | 状态管理 |

## 开发环境搭建

### 1. 环境要求

- Node.js 18+
- npm 或 pnpm

### 2. 安装依赖

```bash
cd campus-wall-monitor-ui
npm install
```

### 3. 启动开发服务器

```bash
npm run dev
```

默认访问地址：`http://localhost:5174`

### 4. Vite 代理配置

开发环境已配置代理，解决跨域问题：

```javascript
// vite.config.js
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true
    },
    '/grafana': {
      target: 'http://localhost:3000',
      changeOrigin: true
    }
  }
}
```

## 核心模块说明

### 1. 路由系统 (router/index.js)

```javascript
const routes = [
  {
    path: '/login',
    component: () => import('@/views/Login.vue'),
    meta: { public: true }           // 公开页面，无需登录
  },
  {
    path: '/',
    component: MainLayout,
    children: [
      { path: 'overview', component: Overview },
      { path: 'moderation', component: Moderation }
    ]
  }
]
```

**导航守卫**：
- 检查 localStorage 中的 Token
- 无 Token 且访问非公开页面 → 重定向到登录页
- 有 Token 且访问登录页 → 重定向到概览页

### 2. HTTP 客户端 (api/http.js)

Axios 实例配置：

```javascript
const http = axios.create({
  baseURL: '/api',
  timeout: 30000
})

// 请求拦截器：自动添加 Token
http.interceptors.request.use(config => {
  const token = localStorage.getItem(TOKEN_KEY)
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器：统一错误处理
http.interceptors.response.use(
  response => response.data,
  error => {
    if (error.response?.status === 401) {
      // Token 过期，跳转到登录页
      localStorage.removeItem(TOKEN_KEY)
      router.push('/login')
    }
    return Promise.reject(error)
  }
)
```

### 3. 登录页 (views/Login.vue)

- 管理员账号密码登录
- 登录成功后保存 Token 到 localStorage
- 跳转到概览页

### 4. 数据概览页 (views/Overview.vue)

- **关键指标卡片**：帖子数、用户数、待审核数等
- **Grafana iframe 嵌入**：实时展示系统监控面板
- 对接后端 `/api/v1/admin/stats/overview`

### 5. 内容审核页 (views/Moderation.vue)

- **待审核列表**：展示 AI 标记的待审核内容
- **审核操作**：
  - 通过：内容正常发布
  - 拒绝：内容不通过，可填写原因
- 对接后端 `/api/v1/admin/moderation/*`

参考 `campus-wall-ops/nginx/monitor-ui.conf`：

```nginx
server {
    listen 80;
    server_name admin.campus-wall.example;

    # SPA 路由
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api/ {
        proxy_pass http://backend:8080/;
    }

    # Grafana 代理
    location /grafana/ {
        proxy_pass http://grafana:3000/;
    }
}
```

## 常见问题

### Q: Grafana iframe 无法加载？

1. 检查 Grafana 是否允许嵌入：`GF_SECURITY_ALLOW_EMBEDDING=true`
2. 检查是否配置了匿名访问：`GF_AUTH_ANONYMOUS_ENABLED=true`
3. 检查 iframe 的 src 地址是否正确

### Q: 登录后跳转失败？

1. 检查 Token 是否正确保存到 localStorage
2. 检查 Axios 拦截器是否正确添加 Authorization 头
3. 检查后端认证接口是否正常工作

### Q: Element Plus 组件样式异常？

确保在 `main.js` 中正确引入样式：

```javascript
import 'element-plus/dist/index.css'
```
