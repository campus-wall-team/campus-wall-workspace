# campus-wall-monitor-ui - 管理后台

这是校园墙项目的管理员后台系统，基于 Vue 3 + Element Plus 开发。它是一套 **RBAC 权限后台 + 运营看板 + 多管理页**：后端独立 `admin_user` 账号体系下发权限码，前端据此驱动路由/菜单/按钮；内置运营数据看板（ECharts），并提供内容审核、举报/反馈/学生认证处理、用户/管理员/角色管理、操作审计、系统配置以及 Grafana 系统监控等多个管理页面。
