# campus_wall 开发文档

## 项目简介

campus_wall 是校园墙项目的核心业务后端服务，负责处理所有业务逻辑，包括用户认证、帖子管理、评论系统、AI 聊天代理、内容审核、私信系统等。

## 开发环境搭建

### 1. 环境要求

- JDK 17+
- Maven 3.8+（或 IDEA 内置）
- MySQL 8.0
- Redis 7.0
- MinIO

### 2. 启动基础设施

```bash
cd campus-wall-ops
docker-compose up -d mysql redis minio
```

### 3. 配置环境变量

```bash
cd campus_wall
cp .env.example .env
# 编辑 .env，配置数据库、Redis、MinIO 连接信息
```

### 4. IDEA 启动

1. IDEA 打开 `campus_wall` 文件夹
2. 等待 Maven 依赖下载
3. 运行 `CampusWallBackendApplication`
4. 访问 `http://localhost:8080/actuator/health`

### 5. 命令行启动

```bash
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

## 核心模块说明

### 1. 认证模块 (common/util/JwtUtil + social)

- **JwtUtil**：JWT Token 生成与验证
- **Interceptor**：请求拦截，验证 Token
- 微信 OAuth2 登录流程：前端获取 code → 后端调用微信接口换取 openid → 生成 JWT Token

### 2. 社区模块 (community)

- **PostController**：帖子 CRUD、点赞、收藏、热帖
- **CommentController**：评论发表、列表、删除
- **CategoryController**：分类管理
- **SearchController**：帖子搜索

核心实体：
- `Post`：帖子（id, userId, categoryId, title, content, images, viewCount, likeCount, status...）
- `Comment`：评论（id, postId, userId, content, parentId...）
- `Category`：分类（id, name, sortOrder...）

### 3. AI 模块 (ai)

- **ChatController**：AI 对话接口
- **PreferenceController**：AI 偏好设置
- **SeniorAssistantService**：AI学长服务，代理调用 GraphRAG

AI 对话流程：
1. 接收用户问题
2. 检查用户配额和偏好
3. 保存用户消息
4. HTTP 调用 GraphRAG `/query`
5. 保存 AI 回复
6. 返回前端

### 4. 社交模块 (social)

- **UserController**：用户信息、登录
- **FollowController**：关注/取消关注
- **MessageController**：私信（REST API + WebSocket）
- **NotificationController**：消息通知

WebSocket 私信：
- 连接地址：`ws://host/ws/chat`
- 认证方式：Header 携带 `Authorization: Bearer <token>`
- 消息格式：`{ type, toUserId, content, timestamp }`

### 5. 管理模块 (admin)

- **ModerationController**：内容审核队列、审核操作
- **FeedbackController**：用户反馈管理
- **FileController**：文件管理
- **StatsController**：数据统计

### 6. 内容审核

三层审核机制：
1. **敏感词过滤**：加载 `sensitive-words.txt`，DFA 算法匹配
2. **AI 复审**：命中可疑规则时，调用 qwen-plus 判定
3. **人工审核**：AI 不确定的内容进入管理后台审核队列

配置项（`application.yaml`）：
```yaml
moderation:
  sensitive-words-path: classpath:sensitive-words.txt
  ai-rescore-enabled: true
```

### 7. 缓存模块 (common/util/RedisUtil)

缓存策略：

| 缓存 Key | 过期时间 | 说明 |
|----------|----------|------|
| `user:info:{userId}` | 2小时 | 用户信息 |
| `post:detail:{postId}` | 30分钟 | 帖子详情 |
| `post:list:{category}:{page}` | 5分钟 | 帖子列表 |
| `comment:list:{postId}` | 10分钟 | 评论列表 |
| `hot:posts` | 10分钟 | 热帖列表 |
| `user:stats:{userId}` | 30分钟 | 用户统计 |

### 8. 定时任务 (task)

- **MetricsCollectionTask**：收集业务指标（ Prometheus 自定义指标）
- **FileCleanupTask**：清理过期临时文件

## 配置说明

### application.yaml（主配置）

```yaml
spring:
  application:
    name: campus-wall-backend
  profiles:
    active: ${SPRING_PROFILES_ACTIVE:dev}
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 50MB

mybatis-plus:
  configuration:
    map-underscore-to-camel-case: true
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl

flyway:
  enabled: true
  locations: classpath:db/migration
  baseline-on-migrate: true
```

### application-dev.yaml（开发配置）

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/campus_wall?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: ${MYSQL_PASSWORD}
  data:
    redis:
      host: localhost
      port: 6379
      password: ${REDIS_PASSWORD}

redis-cache:
  enabled: true
  default-expire: 3600
```


## 常见问题

### Q: Maven 依赖下载慢？

在 `pom.xml` 或 `~/.m2/settings.xml` 中配置阿里云镜像：

```xml
<mirror>
    <id>aliyunmaven</id>
    <mirrorOf>*</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

### Q: Flyway 迁移失败？

1. 检查数据库连接是否正常
2. 检查 `db/migration/` 下的 SQL 语法
3. 如需重置，删除 Flyway 历史表：`DELETE FROM flyway_schema_history;`

### Q: Redis 连接失败？

检查 `application-dev.yaml` 中的 Redis 配置，确保密码正确。

### Q: 上传图片失败？

1. 检查 MinIO 是否正常运行
2. 检查 MinIO 配置（endpoint, accessKey, secretKey）
3. 检查 bucket 是否已创建
