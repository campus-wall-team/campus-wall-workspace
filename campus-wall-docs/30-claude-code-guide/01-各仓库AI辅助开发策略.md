# 各仓库 AI 辅助开发策略

本文档介绍如何在校园墙各仓库中高效使用 Claude Code 辅助开发，包括常见任务模板和提示词技巧。

## 通用策略

### 开始工作前

进入仓库目录后，Claude Code 会自动读取 `.claude/CLAUDE.md`。你可以先确认它已理解项目：

```
请简要描述这个项目的架构和你在 CLAUDE.md 中看到的开发规范。
```

### 任务描述模板

```
【任务类型】新增功能 / 修复 Bug / 重构 / 文档
【涉及模块】xxx
【具体需求】...
【验收标准】...
```

示例：
```
【任务类型】新增功能
【涉及模块】community（帖子模块）
【具体需求】为帖子添加"置顶"功能，管理员可以将重要帖子置顶显示
【验收标准】
1. 帖子表添加 is_top 字段
2. 管理员可以调用 API 置顶/取消置顶
3. 置顶帖子在列表中优先展示
4. 最多同时置顶 3 条帖子
```

### 适合 AI 辅助的场景

| 场景 | 效率提升 |

| 编写单元测试 | 高 |
| 添加 Flyway 迁移 | 中 |
| 代码重构 | 中 |
| 异常处理完善 | 中 |
| 日志添加 | 低 |

### 常用提示词模板

**新增模块**：
```
请在 community 模块下新增一个 "tag"（标签）子模块，包含：
1. Tag 实体类（id, name, post_count, create_time）
2. TagMapper 接口
3. TagService 接口和实现
4. TagController（REST API：列表、详情、创建、删除）
5. 遵循项目的命名规范和分层架构
```

**添加接口**：
```
请在 PostController 中添加一个 "搜索帖子" 接口：
- GET /api/v1/posts/search
- 参数：keyword（必填）、page、size
- 逻辑：根据标题和内容模糊搜索
- 返回：分页帖子列表
- 需要添加 Redis 缓存，缓存 5 分钟
```

**编写测试**：
```
请为 PostService 的 publish 方法编写单元测试，覆盖以下场景：
1. 正常发布
2. 标题为空（应抛异常）
3. 内容包含敏感词（应返回审核状态）
```

**添加 Flyway 迁移**：
```
请新增一个 Flyway 迁移脚本 V1.2__add_post_tag.sql：
1. 创建 post_tag 关联表（post_id, tag_id）
2. 添加索引
3. 符合项目的数据库规范
```

### 注意事项

- AI 生成的 SQL 需要人工检查索引设计
- 涉及事务的操作需确认 `@Transactional` 注解
- 缓存逻辑需确认缓存 key 的唯一性和过期策略
- 不要依赖 AI 生成安全敏感代码（如加密、鉴权）

### 常用提示词模板

**新增页面**：
```
请在 pages/ 下新增一个 "activity"（活动）页面：
1. 页面路径：pages/activity/index.vue
2. 展示活动列表，每项包含标题、时间、地点、封面图
3. 使用 post-card 风格
4. 在 pages.json 中注册
5. 添加到底部导航栏（第6个tab）
```

**新增组件**：
```
请创建一个 "empty-state" 组件：
1. 路径：components/empty-state/index.vue
2. 功能：空状态展示（图标 + 文字 + 可选按钮）
3. Props：icon（图标名）、text（提示文字）、buttonText（按钮文字，可选）
4. 使用 uni-app 组件和 SCSS
```

**API 对接**：
```
请在 api/community.js 中添加活动相关的 API 函数：
1. getActivityList(params) - 获取活动列表
2. getActivityDetail(id) - 获取活动详情
3. joinActivity(id) - 报名活动
4. 使用 request.js 封装，统一错误处理
```

### 注意事项

- uni-app 有平台差异，AI 可能生成小程序不支持的 API，需条件编译
- 图片资源路径需确认正确
- 小程序有包大小限制，注意代码体积

## 提示词技巧

### 1. 角色设定

```
你是一位资深的 Java 后端开发工程师，熟悉 Spring Boot、MyBatis-Plus 和微服务架构。请按照项目规范帮我...
```

### 2. 提供示例

```
请按照以下示例的格式，帮我生成代码：

示例：
```java
@GetMapping("/list")
public Result<PageResult<PostVO>> list(
    @RequestParam(defaultValue = "1") int page,
    @RequestParam(defaultValue = "10") int size
) {
    return Result.success(postService.list(page, size));
}
```

现在请为 CommentController 生成类似的列表接口...
```

### 3. 指定约束

```
请帮我实现，但注意以下约束：
1. 不能使用任何外部库
2. 时间复杂度不超过 O(n)
3. 内存占用不超过 1MB
```

### 4. 迭代优化

```
第一轮：请生成基础版本
第二轮：请添加异常处理
第三轮：请添加单元测试
第四轮：请优化性能
```

## 总结

AI 辅助开发能大幅提升效率，但需要注意：

1. **AI 是助手，不是替代**：关键业务逻辑仍需人工审查
2. **安全敏感代码人工审核**：认证、加密、支付等
3. **测试不可少**：AI 生成的代码必须经过测试验证
4. **持续学习**：根据项目特点积累自己的提示词模板
