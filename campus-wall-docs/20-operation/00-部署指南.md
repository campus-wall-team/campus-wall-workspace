# 部署指南

## 开发环境部署

开发环境使用单机部署，所有服务运行在一台机器上。

### 步骤 1：克隆代码

```bash
mkdir -p ~/workspace && cd ~/workspace
git clone <仓库地址> campus_wall
git clone <仓库地址> campus-wall-frontend
git clone <仓库地址> campus-wall-monitor-ui
git clone <仓库地址> campus-wall-graphrag
git clone <仓库地址> campus-wall-data-pipeline
git clone <仓库地址> campus-wall-alert-adapter
git clone <仓库地址> campus-wall-ops
```

### 步骤 2：启动基础设施

```bash
cd campus-wall-ops

# 配置环境变量
cp .env.example .env
# 编辑 .env，设置密码等

# 启动所有基础设施服务
docker-compose up -d

# 验证启动
docker-compose ps
```

### 步骤 3：启动 Java 后端

```bash
cd campus_wall

# 配置环境变量
cp .env.example .env
# 编辑 .env

# IDEA 中启动 CampusWallBackendApplication
# 或命令行：
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

### 步骤 4：启动前端（开发模式）

```bash
# 用户端前端
cd campus-wall-frontend
npm install
npm run dev:h5

# 管理后台
cd campus-wall-monitor-ui
npm install
npm run dev
```

### 步骤 5：启动 GraphRAG

```bash
# 启动 Ollama
ollama pull bge-m3
ollama serve

# Docker 启动 GraphRAG
cd campus-wall-ops
docker-compose up -d graphrag
```

### 步骤 6：验证

```bash
# 检查各服务
curl http://localhost:8080/actuator/health
curl http://localhost:8001/health
docker-compose ps
```

## 测试环境部署

测试环境与开发环境类似，但使用生产构建：

```bash
# 1. 启动基础设施
cd campus-wall-ops
docker-compose up -d

# 2. 部署 Java 后端（打包后运行）
cd campus_wall
./mvnw clean package -DskipTests
java -jar target/campus-wall-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod

# 3. 部署前端（构建后 Nginx 托管）
cd campus-wall-frontend
npm run build:h5
# 将 dist/build/h5/ 复制到 Nginx 目录

cd campus-wall-monitor-ui
npm run build
# 将 dist/ 复制到 Nginx 目录

# 4. 部署 GraphRAG
cd campus-wall-ops
docker-compose up -d graphrag
```

## 生产环境部署

### 架构设计

```
                    [公网用户]
                         │
                         ▼
              [Cloudflare / 阿里云 CDN]
                         │
                         ▼
                   [Nginx 网关]
                    (SSL 终止)
                         │
        ┌────────────────┼────────────────┐
        ▼                ▼                ▼
   [前端静态文件]    [Java后端×2]      [Grafana]
        │           (负载均衡)            │
        │                │                │
        │                ▼                │
        │         [MySQL 主从]            │
        │         [Redis 哨兵]            │
        │         [MinIO]                 │
        │         [Neo4j]                 │
        │                                 │
        └─────► [Docker Compose 内网] ◄───┘
```

### 步骤 1：服务器准备

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础工具
sudo apt install -y git curl wget vim htop net-tools

# 安装 Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 安装 JDK 17
sudo apt install -y openjdk-17-jdk

# 安装 Node.js 18
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 拉取 Embedding 模型
ollama pull bge-m3
```

### 步骤 2：配置防火墙

```bash
# 仅暴露必要端口
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp      # SSH
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS
sudo ufw enable
```

### 步骤 3：部署基础设施

```bash
cd ~/campus-wall-ops

# 配置生产环境变量
sudo cp .env.example /opt/campus-wall/.env
sudo vim /opt/campus-wall/.env
# 设置强密码！

# 启动 Docker Compose
sudo docker-compose up -d
```

### 步骤 4：部署 Java 后端

```bash
# 创建应用目录
sudo mkdir -p /opt/campus-wall/app
sudo chown -R $USER:$USER /opt/campus-wall

# 构建
cd ~/campus_wall
./mvnw clean package -DskipTests

# 复制 jar 包
cp target/campus-wall-0.0.1-SNAPSHOT.jar /opt/campus-wall/app/

# 复制配置文件
cp src/main/resources/application-prod.yaml /opt/campus-wall/app/
cp .env /opt/campus-wall/app/

# 配置 systemd
sudo cp ~/campus-wall-ops/deploy/campus-wall.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable campus-wall
sudo systemctl start campus-wall

# 检查状态
sudo systemctl status campus-wall
sudo journalctl -u campus-wall -f
```

### 步骤 5：部署前端

```bash
# 构建用户端前端
cd ~/campus-wall-frontend
npm install
npm run build:h5

# 构建管理后台
cd ~/campus-wall-monitor-ui
npm install
npm run build

# 复制到 Nginx 目录
sudo cp -r ~/campus-wall-frontend/dist/build/h5/* /var/www/frontend/
sudo cp -r ~/campus-wall-monitor-ui/dist/* /var/www/monitor/

# 配置 Nginx
sudo cp ~/campus-wall-ops/nginx/monitor-ui.conf /etc/nginx/sites-available/campus-wall
sudo ln -s /etc/nginx/sites-available/campus-wall /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 步骤 6：配置 SSL（Let's Encrypt）

```bash
# 安装 Certbot
sudo apt install -y certbot python3-certbot-nginx

# 申请证书
sudo certbot --nginx -d your-domain.com -d www.your-domain.com

# 自动续期
sudo certbot renew --dry-run
```

### 步骤 7：启动 Ollama 服务

```bash
# 创建 systemd 服务
sudo tee /etc/systemd/system/ollama.service > /dev/null <<EOF
[Unit]
Description=Ollama Service
After=network.target

[Service]
Type=simple
User=$USER
ExecStart=/usr/local/bin/ollama serve
Restart=always

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable ollama
sudo systemctl start ollama
```

### 步骤 8：验证部署

```bash
# 检查所有服务状态
sudo systemctl status campus-wall
sudo systemctl status nginx
sudo systemctl status ollama
sudo docker-compose ps

# 测试 API
curl https://your-domain.com/api/v1/posts/list
curl https://your-domain.com/health

# 测试 GraphRAG
curl http://localhost:8001/health
```

## 备份策略

### 数据库备份

```bash
#!/bin/bash
# backup.sh

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR=/opt/backups

# MySQL 备份
docker exec campus-mysql mysqldump -uroot -p$MYSQL_ROOT_PASSWORD campus_wall > $BACKUP_DIR/mysql_$DATE.sql

# Neo4j 备份
docker exec campus-neo4j neo4j-admin database dump neo4j --to-path=$BACKUP_DIR/neo4j_$DATE.dump

# 压缩
tar czf $BACKUP_DIR/backup_$DATE.tar.gz $BACKUP_DIR/mysql_$DATE.sql $BACKUP_DIR/neo4j_$DATE.dump

# 保留最近 7 天
find $BACKUP_DIR -name "backup_*.tar.gz" -mtime +7 -delete
```

添加到 crontab：
```bash
0 2 * * * /opt/campus-wall/scripts/backup.sh
```

## 升级流程

### 后端升级

```bash
# 1. 拉取最新代码
cd ~/campus_wall
git pull origin main

# 2. 编译
./mvnw clean package -DskipTests

# 3. 停止旧服务
sudo systemctl stop campus-wall

# 4. 替换 jar 包
cp target/campus-wall-0.0.1-SNAPSHOT.jar /opt/campus-wall/app/

# 5. 启动新服务
sudo systemctl start campus-wall

# 6. 验证
curl http://localhost:8080/actuator/health
```

### 前端升级

```bash
# 1. 拉取最新代码
cd ~/campus-wall-frontend
git pull origin main

# 2. 构建
npm install
npm run build:h5

# 3. 替换静态文件
sudo rm -rf /var/www/frontend/*
sudo cp -r dist/build/h5/* /var/www/frontend/
```

### Docker 服务升级

```bash
cd ~/campus-wall-ops

# 拉取最新镜像
docker-compose pull

# 重建并启动
docker-compose up -d --build

# 清理旧镜像
docker image prune -f
```

## 回滚策略

1. **后端回滚**：保留上一个版本的 jar 包，停止当前服务，启动旧版本
2. **前端回滚**：保留上一个版本的构建产物，直接替换
3. **数据库回滚**：使用 Flyway 迁移回滚或使用数据库备份恢复
4. **Docker 回滚**：使用 `docker-compose up -d` 配合旧版本镜像标签
