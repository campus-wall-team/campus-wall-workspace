# 常见问题排查

本文档汇总校园墙项目开发和运维中的常见问题及解决方案。

## 服务启动问题

### Java 后端启动失败

#### 问题：端口 8080 被占用

**现象**：
```
Web server failed to start. Port 8080 was already in use.
```

**解决**：
```bash
# 查找占用进程
lsof -i :8080        # macOS/Linux
netstat -ano | findstr :8080  # Windows

# 终止进程 或 修改端口
# application-dev.yaml:
server:
  port: 8081
```

#### 问题：数据库连接失败

**现象**：
```
Communications link failure
```

**排查步骤**：
1. 检查 MySQL 容器是否运行：`docker ps | grep mysql`
2. 检查 MySQL 端口是否可连接：`mysql -hlocalhost -P3306 -uroot -p`
3. 检查 `application-dev.yaml` 中的数据库配置
4. 检查密码是否正确

**解决**：
```bash
# 重启 MySQL
docker-compose restart mysql

# 或重新初始化
docker-compose down -v
docker-compose up -d mysql
```

#### 问题：Flyway 迁移失败

**现象**：
```
Validate failed: migration checksum mismatch
```

**解决**：
```bash
# 1. 检查迁移脚本是否被修改
# 2. 如确定要重置，删除 Flyway 历史表
mysql -uroot -p -e "USE campus_wall; DELETE FROM flyway_schema_history;"
# 3. 重新启动应用
```

**注意**：生产环境严禁删除 Flyway 历史表！应通过新增迁移脚本解决问题。

#### 问题：Maven 依赖下载失败

**现象**：
```
Could not transfer artifact ... from/to central
```

**解决**：
```xml
<!-- 在 pom.xml 中配置阿里云镜像 -->
<repositories>
    <repository>
        <id>aliyun</id>
        <name>阿里云</name>
        <url>https://maven.aliyun.com/repository/public</url>
    </repository>
</repositories>
```

### 前端启动失败

#### 问题：npm install 失败

**现象**：
```
npm ERR! code ECONNRESET
```

**解决**：
```bash
# 清除缓存
npm cache clean --force

# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 删除 node_modules 重试
rm -rf node_modules package-lock.json
npm install
```

#### 问题：H5 页面空白

**排查步骤**：
1. 打开浏览器开发者工具（F12）
2. 查看 Console 是否有报错
3. 查看 Network 是否有接口 404/500

**常见原因**：
- 后端服务未启动 → 启动 campus_wall
- CORS 跨域问题 → 检查后端 `CorsConfig`
- 路由配置错误 → 检查 `pages.json`

#### 问题：微信小程序编译报错

**常见原因**：
- `appid` 未配置 → 编辑 `manifest.json` 或 `project.config.json`
- 使用了小程序不支持的 API → 使用条件编译 `#ifdef`
- 依赖包过大 → 检查 npm 包体积

## 数据库问题

### MySQL

#### 问题：连接数过多

**排查**：
```sql
SHOW PROCESSLIST;
SHOW STATUS LIKE 'Threads_connected';
```

**解决**：
```sql
-- 增加最大连接数
SET GLOBAL max_connections = 500;

-- 或在 my.cnf 中配置
[mysqld]
max_connections = 500
```

#### 问题：慢查询

**排查**：
```sql
-- 开启慢查询日志
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL long_query_time = 1;

-- 查看慢查询
SELECT * FROM mysql.slow_log ORDER BY start_time DESC LIMIT 10;
```

**解决**：
- 为查询条件字段添加索引
- 优化 SQL 语句
- 使用 EXPLAIN 分析执行计划

### Redis

#### 问题：连接超时

**排查**：
```bash
# 检查 Redis 是否运行
docker ps | grep redis

# 测试连接
redis-cli -h localhost -p 6379 -a password ping
```

**解决**：
```yaml
# application-dev.yaml
spring:
  data:
    redis:
      timeout: 5000ms
      lettuce:
        pool:
          max-active: 20
          max-idle: 10
```

#### 问题：内存不足

**排查**：
```bash
redis-cli info memory
```

**解决**：
```bash
# 设置最大内存和淘汰策略
redis-cli config set maxmemory 256mb
redis-cli config set maxmemory-policy allkeys-lru
```

## AI 服务问题

### GraphRAG

#### 问题：Neo4j 连接失败

**现象**：
```
Failed to establish connection to Neo4j
```

**排查**：
1. 检查 Neo4j 容器：`docker ps | grep neo4j`
2. 检查端口：`nc -zv localhost 7688`
3. 检查密码：`.env` 中的 `NEO4J_PASSWORD`

**解决**：
```bash
# 重置 Neo4j 密码
docker-compose exec neo4j neo4j-admin dbms set-initial-password new_password
```

#### 问题：Embedding 失败

**现象**：
```
Connection refused to Ollama
```

**排查**：
1. 检查 Ollama 是否运行：`curl http://localhost:11434/api/tags`
2. 检查 bge-m3 是否已拉取：`ollama list`
3. 容器内访问需要使用 `host.docker.internal:11434`

#### 问题：回答质量差

**排查**：
1. 知识图谱中数据量是否充足
2. 检查向量检索的 top_k 值
3. 检查 Chat LLM 的 temperature 设置

**优化**：
- 增加更多文档到知识图谱
- 调整检索参数
- 更换更强的 Chat LLM 模型

## 网络问题

### 跨域问题 (CORS)

**现象**：
```
Access to fetch at 'http://localhost:8080/...' from origin 'http://localhost:5173'
has been blocked by CORS policy
```

**解决**：
```java
// campus_wall/config/CorsConfig.java
@Configuration
public class CorsConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/**")
            .allowedOrigins("http://localhost:5173", "http://localhost:5174")
            .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
            .allowedHeaders("*")
            .allowCredentials(true);
    }
}
```

### WebSocket 连接失败

**现象**：
```
WebSocket connection to 'ws://localhost/ws/chat' failed
```

**排查**：
1. 检查后端 WebSocket 配置是否正确
2. 检查 Nginx 代理是否支持 WebSocket
3. 检查防火墙是否放行端口

**Nginx WebSocket 配置**：
```nginx
location /ws/ {
    proxy_pass http://backend:8080;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
}
```

## 性能问题

### 后端响应慢

**排查**：
```bash
# 查看应用日志
tail -f logs/campus-wall.log

# 查看 JVM GC 情况
jstat -gcutil $(jps | grep CampusWallBackendApplication | awk '{print $1}') 1000

# 线程 dump
jstack $(jps | grep CampusWallBackendApplication | awk '{print $1}') > threaddump.txt
```

**常见原因及解决**：

| 原因 | 解决 |
|------|------|
| 数据库慢查询 | 添加索引、优化 SQL |
| 缓存未命中 | 检查 Redis 配置、调整缓存策略 |
| 内存不足 | 增加 JVM 堆内存、优化对象创建 |
| 线程阻塞 | 检查死锁、优化同步代码 |
| 外部服务慢 | 添加超时配置、降级处理 |

### 前端卡顿

**排查**：
1. 浏览器开发者工具 Performance 面板
2. 检查是否有大量重渲染
3. 检查是否有内存泄漏

**优化**：
- 使用 `v-once` 或 `memo` 减少不必要的渲染
- 大列表使用虚拟滚动
- 图片懒加载

## 安全问题

### Token 泄露

**处理**：
1. 立即重置 JWT 密钥
2. 强制所有用户重新登录
3. 检查日志确认泄露范围

### 敏感信息硬编码

**排查**：
```bash
# 搜索代码中的密钥
grep -r "api_key" --include="*.java" --include="*.py" --include="*.js"
grep -r "password" --include="*.java" --include="*.py" --include="*.js"
```

**规范**：
- 所有密钥使用环境变量
- 定期轮换密钥
- 生产环境密码强度要求

## 日志排查

### 查看各服务日志

```bash
# Java 后端
journalctl -u campus-wall -f
# 或
tail -f /opt/campus-wall/logs/app.log

# Docker 服务
docker-compose logs -f campus-mysql
docker-compose logs -f campus-redis
docker-compose logs -f campus-graphrag

# Nginx
sudo tail -f /var/log/nginx/access.log
sudo tail -f /var/log/nginx/error.log
```

### 日志级别

| 级别 | 使用场景 |
|------|----------|
| ERROR | 系统错误，需要立即处理 |
| WARN | 警告，可能需要关注 |
| INFO | 正常业务日志 |
| DEBUG | 开发调试，生产环境关闭 |

```yaml
# application.yaml 配置日志级别
logging:
  level:
    com.jyu.campus: INFO
    org.springframework.web: WARN
```

## 其他问题

### 时区问题

**现象**：数据库时间与系统时间相差 8 小时

**解决**：
```yaml
# application.yaml
spring:
  jackson:
    time-zone: Asia/Shanghai
  datasource:
    url: jdbc:mysql://localhost:3306/campus_wall?serverTimezone=Asia/Shanghai
```

```bash
# Docker 容器时区
docker-compose.yml:
  environment:
    - TZ=Asia/Shanghai
```

### 文件上传失败

**排查**：
1. 检查文件大小是否超过限制（默认 10MB）
2. 检查 MinIO 服务是否正常运行
3. 检查 MinIO bucket 是否存在

```bash
# 检查 MinIO
curl http://localhost:9000/minio/health/live

# 创建 bucket
docker-compose exec minio mc mb /data/campus-wall
```

### 微信登录失败

**排查**：
1. 检查 `WECHAT_APP_ID` 和 `WECHAT_APP_SECRET` 是否正确
2. 检查微信开放平台的授权域名配置
3. 检查前端跳转 URL 是否在授权域名下
