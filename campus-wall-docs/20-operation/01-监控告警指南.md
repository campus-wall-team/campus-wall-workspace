## Prometheus 指标说明

### 访问 Prometheus

URL: `http://localhost:9090`

### 核心指标

#### 1. JVM 指标 (campus_wall)

| 指标名 | 类型 | 说明 | 查询示例 |
|--------|------|------|----------|
| `jvm_memory_used_bytes` | Gauge | JVM 已用内存 | `jvm_memory_used_bytes{area="heap"}` |
| `jvm_memory_max_bytes` | Gauge | JVM 最大内存 | `jvm_memory_max_bytes{area="heap"}` |
| `jvm_gc_pause_seconds_count` | Counter | GC 次数 | `rate(jvm_gc_pause_seconds_count[5m])` |
| `jvm_threads_live_threads` | Gauge | 活跃线程数 | `jvm_threads_live_threads` |
| `process_cpu_usage` | Gauge | CPU 使用率 | `process_cpu_usage` |

**内存使用率计算**：
```promql
jvm_memory_used_bytes{area="heap"} / jvm_memory_max_bytes{area="heap"} * 100
```

#### 2. HTTP 请求指标 (campus_wall)

| 指标名 | 类型 | 说明 |
|--------|------|------|
| `http_server_requests_seconds_count` | Counter | 请求总数 |
| `http_server_requests_seconds_sum` | Counter | 请求耗时总和 |
| `http_server_requests_seconds_bucket` | Histogram | 请求耗时分布 |

**QPS 计算**：
```promql
rate(http_server_requests_seconds_count[1m])
```

**错误率计算**：
```promql
rate(http_server_requests_seconds_count{status=~"5.."}[5m])
/
rate(http_server_requests_seconds_count[5m]) * 100
```

**P99 延迟**：
```promql
histogram_quantile(0.99,
  rate(http_server_requests_seconds_bucket[5m])
)
```

#### 3. 主机指标 (node-exporter)

| 指标名 | 说明 |
|--------|------|
| `node_cpu_seconds_total` | CPU 时间 |
| `node_memory_MemTotal_bytes` | 总内存 |
| `node_memory_MemAvailable_bytes` | 可用内存 |
| `node_filesystem_avail_bytes` | 磁盘可用空间 |
| `node_network_receive_bytes_total` | 网络接收 |
| `node_network_transmit_bytes_total` | 网络发送 |

**CPU 使用率**：
```promql
100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
```

**内存使用率**：
```promql
(1 - node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes) * 100
```

**磁盘使用率**：
```promql
(1 - node_filesystem_avail_bytes / node_filesystem_size_bytes) * 100
```

#### 4. Redis 指标 (redis-exporter)

| 指标名 | 说明 |
|--------|------|
| `redis_connected_clients` | 连接数 |
| `redis_memory_used_bytes` | 已用内存 |
| `redis_keyspace_hits_total` | 命中次数 |
| `redis_keyspace_misses_total` | 未命中次数 |

**缓存命中率**：
```promql
redis_keyspace_hits_total / (redis_keyspace_hits_total + redis_keyspace_misses_total) * 100
```

#### 5. MySQL 指标 (mysqld-exporter)

| 指标名 | 说明 |
|--------|------|
| `mysql_global_status_threads_connected` | 连接数 |
| `mysql_global_status_slow_queries` | 慢查询数 |
| `mysql_global_status_innodb_row_ops_total` | InnoDB 行操作 |

#### 6. 探针指标 (blackbox-exporter)

| 指标名 | 说明 |
|--------|------|
| `probe_success` | 探针是否成功 |
| `probe_duration_seconds` | 探针耗时 |
| `probe_http_status_code` | HTTP 状态码 |

## Grafana 面板

### 访问 Grafana

URL: `http://localhost:3000`
- 默认用户名：`admin`
- 密码：`.env` 中 `GF_SECURITY_ADMIN_PASSWORD`

### 面板列表

| 面板 | 文件 | 说明 |
|------|------|------|
| 业务指标 | `business.json` | 待审核队列深度等 |
| 系统资源 | `host-system.json` | CPU / 内存 / 磁盘 / 网络 |
| JVM 应用 | `jvm-app.json` | Heap / GC / Threads / HTTP |

### 自定义面板

1. 登录 Grafana
2. 点击「+」→「新建面板」
3. 选择 Prometheus 数据源
4. 输入 PromQL 查询
5. 配置可视化类型（Graph / Stat / Table 等）
6. 保存面板

## Alertmanager 告警

### 告警规则分类

#### 1. 服务可用性告警

```yaml
- alert: ServiceDown
  expr: up == 0
  for: 1m
  labels:
    severity: critical
  annotations:
    summary: "服务 {{ $labels.job }} 宕机"
    description: "服务 {{ $labels.instance }} 在 1 分钟内不可达"

- alert: BlackboxProbeFailed
  expr: probe_success == 0
  for: 1m
  labels:
    severity: critical
  annotations:
    summary: "探针检测失败: {{ $labels.instance }}"
```

#### 2. 主机资源告警

```yaml
- alert: HostHighMemory
  expr: (1 - node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes) * 100 > 90
  for: 5m
  labels:
    severity: warning
  annotations:
    summary: "主机 {{ $labels.instance }} 内存使用率过高"
    description: "内存使用率: {{ $value }}%"

- alert: HostHighDisk
  expr: (1 - node_filesystem_avail_bytes / node_filesystem_size_bytes) * 100 > 85
  for: 5m
  labels:
    severity: warning

- alert: HostHighCPU
  expr: 100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100) > 90
  for: 5m
  labels:
    severity: warning
```

#### 3. 应用告警

```yaml
- alert: JvmHeapHigh
  expr: jvm_memory_used_bytes{area="heap"} / jvm_memory_max_bytes{area="heap"} * 100 > 90
  for: 5m
  labels:
    severity: warning
  annotations:
    summary: "JVM Heap 使用率过高"
    description: "Heap 使用率: {{ $value }}%"

- alert: HttpServerErrorRateHigh
  expr: rate(http_server_requests_seconds_count{status=~"5.."}[5m]) / rate(http_server_requests_seconds_count[5m]) * 100 > 5
  for: 5m
  labels:
    severity: critical
  annotations:
    summary: "HTTP 5xx 错误率过高"
    description: "错误率: {{ $value }}%"
```

#### 4. 业务告警

```yaml
- alert: ModerationBacklog
  expr: campus_wall_moderation_pending_count > 50
  for: 10m
  labels:
    severity: warning
  annotations:
    summary: "审核队列积压"
    description: "待审核内容: {{ $value }} 条"
```

### 告警路由配置

```yaml
# alertmanager.yml
route:
  group_by: ['alertname', 'job']
  group_wait: 30s
  group_interval: 5m
  repeat_interval: 4h
  receiver: 'webhook'

  routes:
    # critical 级别立即发送
    - match:
        severity: critical
      group_wait: 10s
      repeat_interval: 1h

    # warning 级别合并发送
    - match:
        severity: warning
      group_wait: 1m
      repeat_interval: 4h

receivers:
  - name: 'webhook'
    webhook_configs:
      - url: 'http://campus-alert-adapter:9094/alert'
        send_resolved: true

inhibit_rules:
  # critical 告警抑制 warning 告警
  - source_match:
      severity: 'critical'
    target_match:
      severity: 'warning'
    equal: ['alertname', 'instance']
```

## 监控检查清单

### 日常检查

- [ ] Grafana 面板是否正常显示
- [ ] 各服务 up 指标是否为 1
- [ ] JVM Heap 使用率是否 < 80%
- [ ] HTTP 错误率是否 < 1%
- [ ] 主机 CPU / 内存 / 磁盘是否正常

### 告警响应

| 告警级别 | 响应时间 | 处理方式 |
|----------|----------|----------|
| critical | 5 分钟内 | 立即处理，必要时回滚 |
| warning | 30 分钟内 | 评估影响，安排处理 |

### 常用 PromQL 查询

```promql
# 查看所有服务状态
up

# 查看最近 5 分钟 QPS
rate(http_server_requests_seconds_count[5m])

# 查看错误请求
http_server_requests_seconds_count{status=~"5.."}

# 查看慢查询（> 1s）
http_server_requests_seconds_bucket{uri!="/actuator/prometheus",le="1.0"}

# 查看 Redis 连接数
redis_connected_clients

# 查看 MySQL 连接数
mysql_global_status_threads_connected
```
